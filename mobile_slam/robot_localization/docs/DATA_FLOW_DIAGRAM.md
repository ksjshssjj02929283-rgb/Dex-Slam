## 时序图

### 单次测量处理时序

```
时间线 ───────────────────────────────────────────────────────►

t₀: 传感器测量
    │
    │  IMU: [ax, ay, az, wx, wy, wz, roll, pitch, yaw]
    │  Odom: [x, y, vx, vy, yaw, vyaw]
    │
    ▼
t₁: ROS回调
    │
    │  imuCallback() / odomCallback()
    │  • 提取数据
    │  • 坐标转换
    │  • 协方差验证
    │
    ▼
t₂: 入队
    │
    │  enqueueMeasurement()
    │  • 创建Measurement对象
    │  • 按时间戳插入优先队列
    │
    ▼
t₃: 主循环轮询
    │
    │  integrateMeasurements()
    │  • 检查队列
    │  • 取出最早测量
    │
    ▼
t₄: 预测
    │
    │  predict(Δt)
    │  • x̂⁻ = f(x̂, u, Δt)
    │  • P⁻ = F·P·Fᵀ + Q
    │
    │  耗时: ~0.1-0.5 ms
    │
    ▼
t₅: 校正
    │
    │  correct(z)
    │  • y = z - h(x̂⁻)
    │  • S = H·P⁻·Hᵀ + R
    │  • K = P⁻·Hᵀ·S⁻¹
    │  • x̂ = x̂⁻ + K·y
    │  • P = (I - K·H)·P⁻
    │
    │  耗时: ~0.5-2 ms
    │
    ▼
t₆: 发布
    │
    │  publishOdometry()
    │  publishTransform()
    │  publishAcceleration()
    │
    │  耗时: ~0.1 ms
    │
    ▼
t₇: 完成
```

## 状态向量传播示例

### 运动模型（简化版）

```
给定当前状态 x̂ₖ₋₁ 和控制输入 uₖ₋₁，时间步长 Δt：

位置更新:
  xₖ = xₖ₋₁ + vxₖ₋₁·cos(yawₖ₋₁)·Δt - vyₖ₋₁·sin(yawₖ₋₁)·Δt
  yₖ = yₖ₋₁ + vxₖ₋₁·sin(yawₖ₋₁)·Δt + vyₖ₋₁·cos(yawₖ₋₁)·Δt
  zₖ = zₖ₋₁ + vzₖ₋₁·Δt

姿态更新:
  rollₖ  = rollₖ₋₁  + vrollₖ₋₁·Δt
  pitchₖ = pitchₖ₋₁ + vpitchₖ₋₁·Δt
  yawₖ   = yawₖ₋₁   + vyawₖ₋₁·Δt

速度更新 (如果有控制输入):
  vxₖ = vxₖ₋₁ + uₓ·Δt + axₖ₋₁·Δt
  vyₖ = vyₖ₋₁ + uᵧ·Δt + ayₖ₋₁·Δt
  vzₖ = vzₖ₋₁ + u_z·Δt + azₖ₋₁·Δt

角速度更新:
  vrollₖ  = vrollₖ₋₁  + 0  (或来自控制)
  vpitchₖ = vpitchₖ₋₁ + 0
  vyawₖ   = vyawₖ₋₁   + u_vyaw·Δt

加速度更新:
  axₖ = axₖ₋₁  (假设恒定)
  ayₖ = ayₖ₋₁
  azₖ = azₖ₋₁
```

## 测量模型示例

### IMU测量

```
测量向量 z_imu = [roll, pitch, yaw, wx, wy, wz, ax, ay, az]ᵀ
```

## 关键时刻

### 启动时刻

```
T = 0s: 节点启动
  • 加载参数
  • 创建订阅者和发布者
  • 初始化滤波器 (initialized_ = false)

T = 0.1s: 首个IMU到达
  • imuCallback()
  • 数据入队
  • 但 initialized_ = false，不处理

T = 0.15s: 首个Odom到达
  • odomCallback()
  • 数据入队
  • 仍然 initialized_ = false

T = 0.2s: 主循环检查
  • integrateMeasurements()
  • 检测到两种传感器都有数据
  • 初始化滤波器:
    - x̂₀ = [odom.x, odom.y, 0, imu.roll, imu.pitch, imu.yaw, ...]
    - P₀ = initial_estimate_covariance
    - initialized_ = true
  • 开始正常处理

T > 0.2s: 持续运行
  • 每个测量到达 → 入队 → 预测 → 校正 → 发布
```

### GPS首次定位时刻

```
T = 0s: NavSatTransform启动
  • datum_initialized_ = false
  • 等待 GPS + Odom + IMU

T = 5s: 首个有效GPS
  • GPS status = STATUS_FIX
  • 但 Odom 或 IMU 未到达
  • 继续等待

T = 5.1s: Odom 和 IMU 都已接收
  • gpsFixCallback()
  • 设置基准点:
    - datum_lat = gps.latitude
    - datum_lon = gps.longitude
    - datum_alt = gps.altitude
  • 初始化UTM投影
  • datum_initialized_ = true
  • 开始发布 /odometry/gps

T > 5.1s: 持续转换
  • 每个GPS测量 → UTM → 本地坐标 → /odometry/gps
```
