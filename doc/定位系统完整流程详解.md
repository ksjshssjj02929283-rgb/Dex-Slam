## 1. 地图生成

### 1.1 建图流程回顾

```
SLAM建图（参考SLAM文档）
    ↓
关键帧点云 + 优化位姿
    ↓
全局地图点云聚合
    ↓
地图分块切分
    ↓
保存为TiledMap
```

### 1.2 地图分块策略

#### 1.2.1 分块原理

```cpp
// 100m × 100m 的Chunk划分
Vec2i GetChunkId(const Vec3d& pos) {
    int x = floor(pos.x() / chunk_size_);  // chunk_size_ = 100.0
    int y = floor(pos.y() / chunk_size_);
    return Vec2i(x, y);
}
```

**示例**：
```
世界坐标系:
  位置 (150, 250, 10) → Chunk (1, 2)
  位置 (-50, 80, 5)   → Chunk (-1, 0)
  位置 (0, 0, 0)      → Chunk (0, 0)
```

#### 1.2.2 地图文件结构

```
data/new_map/
├── index.txt              # 地图索引（必须）
│   ├─ 原点坐标
│   ├─ Chunk列表（ID, Grid, 文件路径）
│   └─ 功能点列表
│
├── chunk_0_0.pcd          # 静态地图块
├── chunk_0_1.pcd
├── chunk_1_0.pcd
├── ...
│
├── chunk_0_0_dyn.pcd      # 动态地图块（可选）
├── chunk_0_1_dyn.pcd
├── ...
│
├── global.pcd             # 完整地图（可视化用）
├── map.pgm                # 2D栅格地图（导航用）
└── map.yaml               # 栅格地图元数据
```

#### 1.2.3 Index文件格式

```
# index.txt 内容示例
0.0 0.0 0.0                    # 地图原点 (x, y, z)
0 0 0 /path/chunk_0.pcd       # Chunk ID, Grid(x,y), 文件路径
1 0 1 /path/chunk_1.pcd
2 1 0 /path/chunk_2.pcd
...
# functional points           # 功能点标记
start 10.0 20.0 0.0 0 0 0 1  # 名称 x y z qx qy qz qw
```

### 1.3 地图分层

Lightning-LM使用**动静态分层**地图：

| 层级 | 来源 | 更新 | 用途 |
|------|------|------|------|
| **静态层** | SLAM建图 | 不变 | 主要定位依据 |
| **动态层** | 实时定位更新 | 实时 | 补充静态地图，适应环境变化 |

#### 1.3.1 静态地图

**特点**：
- 来自SLAM建图的后端优化位姿
- 存储为PCD文件，按Chunk分块
- 加载后不再修改

**生成代码**：
```cpp
CloudPtr GetGlobalMap(bool use_lio_pose = false) {
    CloudPtr global_map(new PointCloudType);
    
    for (auto &kf : all_keyframes_) {
        CloudPtr cloud_trans(new PointCloudType);
        SE3 pose = use_lio_pose ? kf->GetLIOPose() : kf->GetOptPose();
        pcl::transformPointCloud(*kf->GetCloud(), *cloud_trans, pose.matrix());
        *global_map += *cloud_trans;
    }
    
    return global_map;
}
```

#### 1.3.2 动态地图

**特点**：
- 实时定位过程中累积的点云
- 补充静态地图中可能发生变化的区域
- 可配置保存策略

**动态层策略**：

```cpp
enum class DynamicCloudPolicy {
    SHORT,       // 短期保留：车辆移出区域后清空
    LONG,        // 长期保留：保留在内存但不存盘
    PERSISTENT   // 永久保留：存盘，下次启动加载
};
```

**更新条件**：
```cpp
// 1. 定位成功
// 2. 与上次更新间隔一定距离/时间
// 3. 定位分值足够高

if (loc_success &&
    (distance > update_kf_dis_ || time > update_kf_time_) &&
    score > update_lidar_loc_score_) {
    
    // 添加到动态层
    map_->UpdateDynamicCloud(cloud_world, true);
}
```

## 2. 地图加载

### 2.1 加载流程

```
[初始化]
    ↓
LoadMapIndex()  ────┐
    - 读取index.txt  │
    - 解析Chunk信息  │  不加载点云
    - 解析功能点     │  仅索引
    ↓               │
功能点初始化 ────────┘
    ↓
LoadOnPose(fp_pose)  ←─── 根据功能点位置
    ↓
[加载附近Chunk]
```

### 2.2 索引加载

```cpp
bool TiledMap::LoadMapIndex() {
    std::ifstream fin(map_path_ + "/index.txt");
    
    // 1. 读取原点
    fin >> origin_[0] >> origin_[1] >> origin_[2];
    
    // 2. 读取Chunk信息（不加载点云）
    while (!fin.eof()) {
        int id;
        Vec2i grid;
        std::string path;
        fin >> id >> grid[0] >> grid[1] >> path;
        
        auto ck = std::make_shared<MapChunk>(id, grid, path);
        static_chunks_.emplace(grid, ck);  // 仅存储索引
        id_to_grid_.emplace(id, grid);
    }
    
    // 3. 读取功能点
    // format: name x y z qx qy qz qw
    func_points_.emplace_back(name, SE3(q, t));
    
    return true;
}
```

**关键**：
- 仅加载索引，不加载点云（节省内存）
- 建立 `id → grid` 和 `grid → chunk` 的映射
- 功能点用于初始化定位

### 2.3 按需加载

#### 2.3.1 加载策略

```cpp
void TiledMap::LoadOnPose(const SE3& pose) {
    Vec2i current_grid = Pos2Grid(pose.translation());
    
    // 加载 load_map_size_ 范围内的Chunk
    for (const auto& cp : static_chunks_) {
        Vec2i d = cp.first - current_grid;
        int manhattan_dist = abs(d[0]) + abs(d[1]);
        
        if (manhattan_dist <= load_map_size_) {  // 默认 = 2
            if (!IsLoaded(cp.first)) {
                cp.second->LoadCloud();  // 从硬盘加载PCD
                loaded_chunks_.emplace(cp.first);
                
                // 同时创建对应的动态层Chunk
                CreateDynamicChunk(cp.first);
            }
        }
    }
    
    // 卸载 unload_map_size_ 范围外的Chunk
    for (auto iter = loaded_chunks_.begin(); iter != loaded_chunks_.end();) {
        Vec2i g = *iter;
        Vec2i d = g - current_grid;
        int manhattan_dist = abs(d[0]) + abs(d[1]);
        
        if (manhattan_dist > unload_map_size_) {  // 默认 = 3
            UnloadChunk(g);
            iter = loaded_chunks_.erase(iter);
        } else {
            ++iter;
        }
    }
}
```

**加载范围示例** (`load_map_size=2, unload_map_size=3`):

```
当前位置: Chunk (0, 0)

加载范围 (Manhattan距离 ≤ 2):
  +---+---+---+---+---+
  |   | L | L | L |   |
  +---+---+---+---+---+
  | L | L | L | L | L |
  +---+---+---+---+---+
  | L | L | C | L | L |  C = Current
  +---+---+---+---+---+
  | L | L | L | L | L |
  +---+---+---+---+---+
  |   | L | L | L |   |
  +---+---+---+---+---+

卸载范围 (Manhattan距离 > 3):
  超出图示范围的Chunk将被卸载
```

## 3. 重定位（初始化）

### 3.1 初始化流程

```
[未初始化状态]
    ↓
检查初始化方式
    ├─ 外部设置位姿？ ──→ InitWithFP(external_pose)
    │                       ↓
    │                    成功？──→ [初始化完成]
    │                       ↓ 失败
    └─ 功能点初始化 ──→ 遍历所有功能点
                           ↓
                        YawSearch()
                           ↓
                        最高分值 > 阈值？
                           ↓
                        [初始化完成]
```

### 3.2 功能点（Functional Point）

**功能点**是地图中的特殊标记位置，用于辅助初始化。

**来源**：
1. 建图时的起点
2. 手动标记的位置
3. 上次定位成功的位置（recover pose）

**使用**：
```cpp
void LidarLoc::Align(const CloudPtr& input) {
    if (!loc_inited_) {
        // 尝试从功能点初始化
        auto all_fps = map_->GetAllFP();
        
        for (const auto& fp : all_fps) {
            map_->LoadOnPose(fp.pose_);  // 加载该位置附近的地图
            
            if (InitWithFP(input, fp.pose_)) {
                LOG(INFO) << "init with fp: " << fp.name_;
                return;
            }
        }
    }
}
```

### 3.3 航向角搜索（Yaw Search）

由于功能点只提供XY位置，需要搜索最佳航向角。

#### 3.3.1 搜索流程

```cpp
bool LidarLoc::YawSearch(SE3& pose, double& confidence, 
                         CloudPtr input, CloudPtr output) {
    SE3 init_pose = pose;
    auto RPYXYZ = math::SE3ToRollPitchYaw(init_pose);
    double init_yaw = RPYXYZ.yaw;
    
    // 搜索参数
    int step = grid_search_angle_step;      // 默认 60
    double radius = grid_search_angle_range * DEG2RAD;  // 默认 180°
    double angle_search_step = 2 * radius / step;
    
    std::vector<double> searched_yaw;
    std::vector<double> scores(step);
    std::vector<SE3> pose_opti(step);
    
    // 构建搜索角度列表
    for (int i = 0; i < step; ++i) {
        double search_yaw = init_yaw + i * angle_search_step - radius;
        searched_yaw.emplace_back(search_yaw);
    }
    
    // 粗分辨率搜索（并行）
    std::for_each(std::execution::par_unseq, index.begin(), index.end(), 
        [&](int i) {
            RPYXYZ.yaw = searched_yaw[i];
            SE3 pose_esti = math::XYZRPYToSE3(RPYXYZ);
            
            // 使用粗分辨率NDT
            Localize(pose_esti, scores[i], input, output, true);
            pose_opti[i] = pose_esti;
        });
    
    // 找到最佳匹配
    auto best_idx = std::max_element(scores.begin(), scores.end()) - scores.begin();
    confidence = scores[best_idx];
    pose = pose_opti[best_idx];
    
    // 精细化（使用高分辨率NDT）
    if (confidence > min_init_confidence_) {
        Localize(pose, confidence, input, output, false);
    }
    
    return (confidence > min_init_confidence_);
}
```

#### 3.3.2 搜索策略

**参数配置**：
```yaml
grid_search_angle_step: 60     # 搜索步数
grid_search_angle_range: 180.0 # 搜索范围（度）
min_init_confidence: 1.8       # 最小初始化置信度
```

**搜索示例** (60步，180°范围):
```
初始yaw: 0°
搜索范围: -90° 到 +90°
步长: 180° / 60 = 3°

搜索角度:
-90°, -87°, -84°, ..., 0°, ..., 84°, 87°, 90°
```

**两阶段搜索**：
1. **粗搜索** - 5m分辨率NDT，快速排除大部分角度
2. **精搜索** - 1m分辨率NDT，精确定位最佳角度

### 3.4 初始化成功条件

```cpp
bool InitWithFP(CloudPtr input, const SE3& fp_pose) {
    double fitness_score;
    SE3 pose_esti = fp_pose;
    CloudPtr output_cloud(new PointCloudType);
    
    // 执行Yaw搜索
    loc_inited_ = YawSearch(pose_esti, fitness_score, input, output_cloud);
    
    if (loc_inited_) {
        current_abs_pose_ = pose_esti;
        localization_result_.pose_ = pose_esti;
        localization_result_.confidence_ = fitness_score;
        localization_result_.status_ = LocalizationStatus::GOOD;
        
        // 记录初始位姿，用于后续增量定位
        last_abs_pose_ = pose_esti;
        last_lo_pose_ = current_lo_pose_;
        last_dr_pose_ = current_dr_pose_;
        
        return true;
    } else {
        // 失败记录
        fp_init_fail_pose_vec_.emplace_back(fp_pose);
        return false;
    }
}
```

**成功标准**：
- NDT匹配分值 > `min_init_confidence_` (默认1.8)
- 分值越高表示匹配越好，通常：
  - `> 2.0`: 优秀
  - `1.5 ~ 2.0`: 良好
  - `1.0 ~ 1.5`: 可接受
  - `< 1.0`: 失败

### 3.5 初始化失败处理

```cpp
// 避免在同一位置反复尝试
if (!fp_init_fail_pose_vec_.empty() && current_dr_pose_set_) {
    SE3 last_tried_pose = fp_init_fail_pose_vec_.back();
    
    // 检查是否应该重试
    bool should_try =
        (current_time - fp_last_tried_time_) > 2.0 ||          // 时间间隔
        (current_dr_pose_.translation() - 
         last_tried_pose.translation()).norm() > 0.3 ||        // 位置变化
        (current_dr_pose_.so3().inverse() * 
         last_tried_pose.so3()).log().norm() > 10 * DEG2RAD;  // 角度变化
    
    if (!should_try) {
        LOG(INFO) << "skip trying init, please move to another place.";
        return;
    }
}
```

## 4. 实时定位

### 4.1 定位主流程

```cpp
void LidarLoc::Align(const CloudPtr& input) {
    current_timestamp_ = ToSec(input->header.stamp) + lidar_time_interval;
    
    // 1. 分配当前帧的LO和DR位姿
    AssignLOPose(current_timestamp_);
    AssignDRPose(current_timestamp_);
    
    // 2. 静止检测
    if (parking_ && loc_inited_) {
        // 输出固定位姿
        current_abs_pose_ = last_abs_pose_;
        return;
    }
    
    // 3. 初始化处理（如果未初始化）
    if (!loc_inited_) {
        // 尝试功能点初始化...
        return;
    }
    
    // 4. 构建位姿初值
    SE3 guess_from_lo = ConstructLOGuess();
    SE3 guess_from_dr = ConstructDRGuess();
    SE3 guess_from_self = ConstructSelfGuess();
    
    // 5. 地图加载
    map_->LoadOnPose(guess_from_dr);
    
    // 6. 多假设定位
    double score_lo, score_dr, score_self;
    SE3 res_lo, res_dr, res_self;
    
    Localize(res_lo, score_lo, input, output, false);  // LO预测
    
    if (ShouldTryDR()) {
        Localize(res_dr, score_dr, input, output, false);  // DR预测
    }
    
    if (ShouldTrySelf()) {
        Localize(res_self, score_self, input, output, false);  // 自身预测
    }
    
    // 7. 选择最佳结果
    SE3 best_pose = SelectBestPose(res_lo, res_dr, res_self,
                                   score_lo, score_dr, score_self);
    
    // 8. 退化检测
    if (IsDegenerate(res_lo, res_dr, score_lo, score_dr)) {
        best_pose = guess_from_dr;  // 使用DR
    }
    
    // 9. Force 2D（如果启用）
    if (force_2d_) {
        best_pose = ProjectTo2D(best_pose);
    }
    
    // 10. 更新状态
    current_abs_pose_ = best_pose;
    UpdateLocalizationResult();
    
    // 11. 更新动态地图
    if (ShouldUpdateDynamicMap()) {
        map_->UpdateDynamicCloud(TransformToWorld(input), true);
    }
    
    // 12. 保存恢复位姿
    SaveRecoverPose(best_pose);
}
```

### 4.2 位姿预测构建

#### 4.2.1 LO预测（主要）

```cpp
SE3 guess_from_lo = last_abs_pose_;

if (last_lo_pose_set_ && current_lo_pose_set_) {
    // 使用两帧LO的相对运动
    const SE3 delta = last_lo_pose_.inverse() * current_lo_pose_;
    guess_from_lo = last_abs_pose_ * delta;
}
```

**原理**：
```
上一次绝对位姿: T_w_l(t-1)
上一次LO位姿: T_lio_l(t-1)
当前LO位姿: T_lio_l(t)

LO增量: ΔT = T_lio_l(t-1)^(-1) * T_lio_l(t)
当前预测: T_w_l(t) = T_w_l(t-1) * ΔT
```

#### 4.2.2 DR预测（辅助）

```cpp
SE3 guess_from_dr = guess_from_lo;

if (last_dr_pose_set_ && current_dr_pose_set_) {
    const SE3 delta = last_dr_pose_.inverse() * current_dr_pose_;
    guess_from_dr = last_abs_pose_ * delta;
}
```

**用途**：
- LO失效时的备选
- 检测LO异常
- 退化场景处理

#### 4.2.3 自身预测（备选）

```cpp
SE3 guess_from_self = guess_from_lo;

if (lidar_loc_pose_queue_.size() >= 2) {
    SE3 pred;
    TimedPose match;
    
    // 从历史定位轨迹插值预测
    if (PoseInterp(current_time, lidar_loc_pose_queue_, pred, match, 2.0)) {
        guess_from_self = pred;
    }
}
```

**用途**：
- 平滑运动轨迹
- 检测LO/DR异常

### 4.3 多假设定位

#### 4.3.1 尝试条件

```cpp
bool try_dr = false;
if (((guess_from_dr.translation() - guess_from_lo.translation()).norm() 
     >= try_other_guess_trans_th_) ||  // 默认 0.3m
    ((guess_from_dr.so3().inverse() * guess_from_lo.so3()).log().norm() 
     >= try_other_guess_rot_th_)) {    // 默认 0.5°
    
    LOG(INFO) << "trying dr pose";
    try_dr = true;
}

bool try_self = false;
if (差异足够大 && 与DR也不同) {
    LOG(INFO) << "trying self extrap pose";
    try_self = true;
}
```

**策略**：
- 默认使用LO预测
- 当LO与DR/Self差异较大时，尝试其他假设
- 选择NDT分值最高的结果

#### 4.3.2 结果选择

```cpp
SE3 current_pose_esti = guess_from_lo;
double fitness_score = 0;

// 1. LO定位（必做）
Localize(current_pose_esti, fitness_score, input, output);
double score_lo = fitness_score;
SE3 res_of_lo = current_pose_esti;

// 2. DR定位（按需）
if (try_dr) {
    SE3 res_of_dr = guess_from_dr;
    double score_dr;
    Localize(res_of_dr, score_dr, input, output);
    
    if (score_dr > (fitness_score - 0.1)) {  // DR更好
        current_pose_esti = res_of_dr;
        fitness_score = score_dr;
    }
}

// 3. Self定位（按需）
if (try_self) {
    SE3 res_of_self = guess_from_self;
    double score_self;
    Localize(res_of_self, score_self, input, output);
    
    if (score_self > (fitness_score + 0.1)) {  // Self明显更好
        current_pose_esti = res_of_self;
        fitness_score = score_self;
    }
}
```

### 4.4 NDT配准

```cpp
bool LidarLoc::Localize(SE3& pose, double& confidence, 
                        CloudPtr input, CloudPtr output,
                        bool use_rough_res) {
    Eigen::Matrix4f guess_pose = pose.matrix().cast<float>();
    
    UL lock(match_mutex_);
    NDTType::Ptr ndt = use_rough_res ? pcl_ndt_rough_ : pcl_ndt_;
    
    // 设置源点云
    ndt->setInputSource(input);
    
    // 执行配准
    ndt->align(*output, guess_pose);
    
    // 获取结果
    Eigen::Matrix4f trans = ndt->getFinalTransformation();

    return (confidence > min_init_confidence_);
}
```

```cpp
    UL lock(data_mutex_);
    
    // 检查时间顺序
    if (!dr_pose_queue_.empty()) {
        double last_stamp = dr_pose_queue_.back().timestamp_;
        if (dr_result.timestamp_ < last_stamp) {
            return false;  // 时间回退

    }
    
    return true;
}
```

### 5.3 高频位姿外推

#### 5.3.1 外推策略

```cpp
bool PGO::ExtrapolateLocResult(LocalizationResult& output_result) {
    if (!output_result.valid_) {
        return false;
    }
    
    auto& dr_queue = dr_pose_queue_;
    auto& lo_queue = lidar_odom_pose_queue_;
    
    // 1. 确定外推目标时间（取最新）
    double latest_time = result_.timestamp_;
    if (!dr_queue.empty() && dr_queue.back().timestamp_ > latest_time) {
        latest_time = dr_queue.back().timestamp_;
    }
    if (!lo_queue.empty() && lo_queue.back().timestamp_ > latest_time) {
        latest_time = lo_queue.back().timestamp_;
    }
    
    // 2. 使用DR外推
    if (!dr_queue.empty() && 
        dr_queue.back().timestamp_ > output_result.timestamp_) {
        
        SE3 interp_pose;
        NavState best_match;
        
        // 插值到输出时刻
        bool interp_succ = PoseInterp(
            output_result.timestamp_, dr_queue, interp_pose, best_match);
        
        if (interp_succ) {
            // 计算增量
            SE3 pose_incre = interp_pose.inverse() * 
                            dr_queue.back().GetPose();
            
            // 应用到输出
            output_result.pose_ = output_result.pose_ * pose_incre;
            output_result.timestamp_ = dr_queue.back().timestamp_;
        }
    }
    
    // 3. 如果仍未达到最新时间，用激光定位外推
    if (output_result.timestamp_ < (latest_time - 0.05)) {
        SE3 interp_pose_final;
        TimedPose best_match_final;
        
        if (PoseInterp(latest_time, lidar_loc_pose_queue_, 
                      interp_pose_final, best_match_final, 5.0)) {
            output_result.pose_ = interp_pose_final;
            output_result.timestamp_ = latest_time;
        }
    }
    
    return true;
}
```

```cpp
        }
    }
}
```

### 5.4 平滑滤波

```cpp
class PoseSmoother {
public:
    PoseSmoother(double smooth_factor) : smooth_factor_(smooth_factor) {}
    
    void PushPose(const SE3& pose) {
        if (!initialized_) {
            smoothed_pose_ = pose;
            initialized_ = true;
            return;
        }
        
        // 指数加权移动平均
        // α = smooth_factor (默认 0.01)
        // smooth = (1-α) * smooth_prev + α * pose_new
        
        Vec3d t_smooth = (1.0 - smooth_factor_) * smoothed_pose_.translation() +
                        smooth_factor_ * pose.translation();
        
        // 旋转的球面线性插值
        SO3 r_smooth = SO3::interp(smoothed_pose_.so3(), pose.so3(), 
                                   smooth_factor_);
        
        smoothed_pose_ = SE3(r_smooth, t_smooth);
    }
    
    SE3 GetPose() const { return smoothed_pose_; }
    
private:
    double smooth_factor_;  // 平滑因子，越小越平滑
    SE3 smoothed_pose_;
    bool initialized_ = false;
};
```
