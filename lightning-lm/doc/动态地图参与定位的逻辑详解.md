## 1. 概述

### 1.1 核心结论

**在所有策略下，动态地图参与定位的逻辑是完全相同的**。策略差异仅影响动态层的**生命周期管理**（创建、保留、清空、存盘），而不影响定位算法本身。

### 1.2 定位参与方式

动态地图通过以下统一机制参与NDT定位：

```
每一帧定位流程:
  1. LoadOnPose() - 加载当前位置附近的静态+动态chunks
  2. SetNewTargetForNDT() - 将静态+动态点云设置为NDT目标
  3. Localize() - NDT匹配（对静态+动态融合地图）
  4. UpdateDynamicCloud() - 更新动态层（累积新观测）
```

**关键点**：
- ✅ NDT算法对静态层和动态层一视同仁，统一处理
- ✅ 所有策略都使用相同的`SetNewTargetForNDT()`函数
- ✅ 策略差异只在`LoadOnPose()`的卸载逻辑中体现
- ✅ 动态层是否为空决定其是否参与，而非策略类型

### 2.2 地图更新检测机制

```cpp
/// 独立线程：UpdateMapThread (lidar_loc.cc:404)
void LidarLoc::UpdateMapThread() {
    LOG(INFO) << "UpdateMapThread thread is running";
    while (!update_map_quit_) {
        // 检查静态地图或动态地图是否有更新
        if (map_->MapUpdated() || map_->DynamicMapUpdated()) {
            // 重建NDT目标
            UpdateGlobalMap();
            
            // 可视化更新
            if (ui_) {
                ui_->UpdatePointCloudGlobal(map_->GetStaticCloud());
                ui_->UpdatePointCloudDynamic(map_->GetDynamicCloud());
            }
            
            // 清除更新标志
            map_->CleanMapUpdate();
        }
        usleep(10000);  // 10ms检查一次
    }
}
```

**工作机制**：
1. ⏱️ **每10ms检查一次**地图是否变化
2. 🔄 **MapUpdated()**: 静态地图加载/卸载时返回true
3. 🔄 **DynamicMapUpdated()**: 动态地图创建/清空/更新时返回true
4. 🔨 **UpdateGlobalMap()**: 重新调用`SetNewTargetForNDT()`构建NDT目标

## 3. 关键代码解析

### 3.1 SetNewTargetForNDT - 统一的地图融合逻辑

```cpp
/// tiled_map.h:211-239
/// 这是所有策略共用的函数，无任何策略判断
template <class T>
void SetNewTargetForNDT(T ndt) {
    bool has_cloud = false;
    
    // ==================== 第一步：添加静态层 ====================
    {
        UL lock(static_data_mutex_);
        for (auto& idx : loaded_chunks_) {
            if (!static_chunks_[idx]->cloud_->empty()) {
                has_cloud = true;
            }
            // 所有已加载的静态块都加入NDT目标
            ndt->AddTarget(static_chunks_[idx]->cloud_);
        }
    }

    // ==================== 第二步：添加动态层 ====================
    {
        UL lock(dynamic_data_mutex_);
        for (auto& idx : loaded_chunks_) {
            // 检查该位置是否有对应的动态块
            if (dynamic_chunks_.find(idx) != dynamic_chunks_.end()) {
                // 检查动态块的点云是否非空
                if (dynamic_chunks_[idx]->cloud_ != nullptr) {
                    has_cloud = true;
                    // 添加到NDT目标
                    ndt->AddTarget(dynamic_chunks_[idx]->cloud_);
                }
            }
        }
    }

    // ==================== 第三步：计算NDT网格 ====================
    ndt->ComputeTargetGrids();  // 融合所有点云，构建统一的NDT网格
    if (has_cloud) {
        ndt->initCompute();
    }
}
```

**重要说明**：
1. ✅ **无策略分支**：代码中没有`if (policy_ == SHORT/LONG/PERSISTENT)`的判断
2. ✅ **统一添加**：静态层和动态层通过相同的`AddTarget()`接口添加
3. ✅ **融合处理**：`ComputeTargetGrids()`将所有点云融合成统一的NDT网格
4. ✅ **自动参与**：只要`dynamic_chunks_[idx]->cloud_`非空，就会参与定位

### 3.2 LoadOnPose - 策略差异的唯一体现点

```cpp
/// tiled_map.cc:276
void TiledMap::LoadOnPose(const SE3& pose) {
    Vec2d p = pose.translation().head<2>();
    auto this_grid = Pos2Grid(p);
    
    // ==================== 加载逻辑（所有策略相同） ====================
    for (const auto& cp : static_chunks_) {
        Vec2i d = cp.first - this_grid;
        int n = abs(d[0]) + abs(d[1]);  // 曼哈顿距离
        
        if (n <= options_.load_map_size_) {  // 距离<=2 chunk
            // 加载静态块
            if (loaded_chunks_.find(cp.first) == loaded_chunks_.end()) {
                if (cp.second->cloud_ == nullptr) {
                    cp.second->LoadCloud();
                }
                loaded_chunks_.emplace(cp.first);
                map_updated_ = true;
            }

            // 检查动态块
            auto dyn_iter = dynamic_chunks_.find(cp.first);
            if (dyn_iter == dynamic_chunks_.end()) {
                // 动态块不存在，创建一个新的（空）
                auto new_chunk = std::make_shared<MapChunk>(
                    cp.second->id_, cp.first, 
                    options_.map_path_ + "/" + std::to_string(cp.second->id_) + "_dyn.pcd");
                dynamic_chunks_.emplace(cp.first, new_chunk);
                dynamic_map_updated_ = true;
            } else {
                // 动态块已存在但可能已卸载，重新加载
                if (!dyn_iter->second->loaded_) {
                    dyn_iter->second->LoadCloud();  // 从内存或文件加载
                }
            }
        }
    }

    // ==================== 卸载逻辑（策略差异点） ====================
    for (auto iter = loaded_chunks_.begin(); iter != loaded_chunks_.end();) {
        Vec2i g = *iter;
        Vec2i d = g - this_grid;
        int n = abs(d[0]) + abs(d[1]);
        
        if (n > options_.unload_map_size_) {  // 距离>3 chunk
            // 卸载静态地图（所有策略相同）
            map_updated_ = true;
            iter = loaded_chunks_.erase(iter);

            auto d = dynamic_chunks_.find(g);
            
            // ============ 策略1：SHORT - 清空内存 ============
            if (options_.policy_ == DynamicCloudPolicy::SHORT && 
                d != dynamic_chunks_.end()) {
                dynamic_chunks_[g]->cloud_ = nullptr;  // 直接清空
                dynamic_map_updated_ = true;
            }

            // ============ 策略2：PERSISTENT - 存盘 ============
            if (options_.policy_ == DynamicCloudPolicy::PERSISTENT && 
                d != dynamic_chunks_.end() && d->second->loaded_) {
                
                if (d->second->cloud_ != nullptr && !d->second->cloud_->empty()) {
                    // 选项1: 卸载时存盘
                    if (options_.save_dyn_when_unload_) {
                        std::string filename = options_.map_path_ + "/" + 
                                             std::to_string(d->second->id_) + "_dyn.pcd";
                        d->second->cloud_->width = d->second->cloud_->size();
                        pcl::io::savePCDFileBinaryCompressed(filename, *d->second->cloud_);
                    }
                    
                    // 选项2: 卸载时清空内存
                    if (options_.delete_when_unload_) {
                        d->second->Unload();
                    }
                    // 否则保留在内存中
                }
            }
            
            // ============ 策略3：LONG - 无显式代码 ============
            // LONG策略没有特殊处理，动态层保留在dynamic_chunks_中
        } else {
            iter++;
        }
    }
    
    last_load_grid_ = this_grid;
    last_load_grid_set_ = true;
}
```

### 3.3 UpdateDynamicCloud - 累积新观测

```cpp
/// tiled_map.cc (推测实现)
void TiledMap::UpdateDynamicCloud(CloudPtr cloud_world, bool remove_old) {
    UL lock(dynamic_data_mutex_);
    
    for (size_t i = 0; i < cloud_world->size(); ++i) {
        const auto& pt = cloud_world->points[i];
        
        // 确定点所属的Chunk
        Vec2i grid_idx = Pos2Grid(pt.getVector3fMap().head<2>());
        
        auto chunk_iter = dynamic_chunks_.find(grid_idx);
        if (chunk_iter != dynamic_chunks_.end()) {
            // 确保点云容器存在
            if (chunk_iter->second->cloud_ == nullptr) {
                chunk_iter->second->cloud_.reset(new PointCloudType);
            }
            
            // 添加点到动态Chunk
            chunk_iter->second->cloud_->push_back(pt);
            
            // 容量控制
            if (chunk_iter->second->cloud_->size() > options_.max_pts_in_dyn_chunk_) {
                if (remove_old) {
                    // 移除最老的70%点（FIFO策略）
                    size_t remove_cnt = size_t(0.7 * chunk_iter->second->cloud_->size());
                    chunk_iter->second->cloud_->points.erase(
                        chunk_iter->second->cloud_->points.begin(),
                        chunk_iter->second->cloud_->points.begin() + remove_cnt
                    );
                }
            }
        }
    }
    
    dynamic_map_updated_ = true;  // 触发NDT重建
}
```

## 4. 不同策略下的行为差异

### 4.1 策略对比表

| 阶段 | 不使用动态地图 | SHORT | LONG | PERSISTENT |
|------|---------------|-------|------|------------|
| **LoadOnPose加载** | - | 创建空动态块 | 创建空动态块 | 从文件加载 |
| **SetNewTargetForNDT** | 只添加静态层 | 静态+动态（如有） | 静态+动态（如有） | 静态+动态（如有） |
| **Localize匹配** | 纯静态NDT | 融合NDT | 融合NDT | 融合NDT |
| **UpdateDynamicCloud** | ❌跳过 | ✅累积 | ✅累积 | ✅累积 |
| **LoadOnPose卸载** | - | 清空内存 | 保留内存 | 存盘+可选清空 |
| **程序退出** | - | 不保存 | 不保存 | 保存所有 |
| **下次启动** | - | 空白 | 空白 | 从文件加载 |

### 4.2 动态层状态转换图

#### SHORT策略
```
启动 → [区域A动态层: 不存在]
          ↓ LoadOnPose
      [区域A动态层: 创建，cloud_=nullptr]
          ↓ UpdateDynamicCloud (多次)
      [区域A动态层: cloud_=[5000点]]
          ↓ SetNewTargetForNDT
      [NDT目标: 静态A + 动态A(5000点)]
          ↓ 车辆离开 (距离>300m)
      [LoadOnPose卸载: cloud_=nullptr]
          ↓ SetNewTargetForNDT (下次Update)
      [NDT目标: 静态B + 动态B(空)]
          ↓ 车辆返回区域A
      [LoadOnPose加载: cloud_=nullptr (重新开始)]
```

#### LONG策略
```
启动 → [区域A动态层: 不存在]
          ↓ LoadOnPose
      [区域A动态层: 创建，cloud_=nullptr]
          ↓ UpdateDynamicCloud (多次)
      [区域A动态层: cloud_=[5000点]]
          ↓ SetNewTargetForNDT
      [NDT目标: 静态A + 动态A(5000点)]
          ↓ 车辆离开 (距离>300m)
      [LoadOnPose卸载: cloud_保持=[5000点]]  ← 关键差异
          ↓ 车辆返回区域A
      [LoadOnPose加载: cloud_=[5000点] (继续使用)]
          ↓ UpdateDynamicCloud (继续累积)
      [区域A动态层: cloud_=[8000点]]
          ↓ 程序退出
      [内存释放: 8000点丢失]
```

#### PERSISTENT策略
```
启动 → [区域A动态层: 从A_dyn.pcd加载3000点]  ← 跨会话
          ↓ LoadOnPose
      [区域A动态层: cloud_=[3000点]]
          ↓ UpdateDynamicCloud (多次)
      [区域A动态层: cloud_=[8000点]]
          ↓ SetNewTargetForNDT
      [NDT目标: 静态A + 动态A(8000点)]
          ↓ 车辆离开 (距离>300m)
      [LoadOnPose卸载: 
         - save_dyn_when_unload=true → 存盘A_dyn.pcd(8000点)
         - delete_when_unload=false → 内存保持8000点]
          ↓ 车辆返回区域A
      [LoadOnPose加载: cloud_=[8000点] (从内存或文件)]
          ↓ UpdateDynamicCloud (继续累积)
      [区域A动态层: cloud_=[12000点]]
          ↓ 程序退出
      [保存: A_dyn.pcd(12000点)]
          ↓ 下次启动
      [加载: A_dyn.pcd(12000点)]  ← 长期累积
```

### 4.3 SetNewTargetForNDT的实际行为

**关键理解**：此函数**不关心策略**，只关心点云是否存在。

```
场景1: SHORT策略，首次进入区域A
  loaded_chunks_ = [A]
  static_chunks_[A]->cloud_ = [50000点]
  dynamic_chunks_[A]->cloud_ = nullptr (刚创建)
  
  SetNewTargetForNDT执行:
    ├─ ndt->AddTarget(static_chunks_[A]->cloud_)  ✅ 添加50000点
    └─ if (dynamic_chunks_[A]->cloud_ != nullptr)  ❌ 跳过
  
  结果: NDT目标 = 静态A (50000点)

场景2: SHORT策略，第5次经过区域A（已累积）
  loaded_chunks_ = [A]
  static_chunks_[A]->cloud_ = [50000点]
  dynamic_chunks_[A]->cloud_ = [8000点] (已累积5次)
  
  SetNewTargetForNDT执行:
    ├─ ndt->AddTarget(static_chunks_[A]->cloud_)   ✅ 添加50000点
    └─ ndt->AddTarget(dynamic_chunks_[A]->cloud_)  ✅ 添加8000点
  
  结果: NDT目标 = 静态A (50000点) + 动态A (8000点)

场景3: SHORT策略，离开后再次返回
  loaded_chunks_ = [A]
  static_chunks_[A]->cloud_ = [50000点]
  dynamic_chunks_[A]->cloud_ = nullptr (被SHORT策略清空)
  
  SetNewTargetForNDT执行:
    ├─ ndt->AddTarget(static_chunks_[A]->cloud_)  ✅ 添加50000点
    └─ if (dynamic_chunks_[A]->cloud_ != nullptr)  ❌ 跳过
  
  结果: NDT目标 = 静态A (50000点)，回到初始状态

场景4: PERSISTENT策略，程序重启后首次进入
  loaded_chunks_ = [A]
  static_chunks_[A]->cloud_ = [50000点]
  dynamic_chunks_[A]->cloud_ = [12000点] (从A_dyn.pcd加载)
  
  SetNewTargetForNDT执行:
    ├─ ndt->AddTarget(static_chunks_[A]->cloud_)   ✅ 添加50000点
    └─ ndt->AddTarget(dynamic_chunks_[A]->cloud_)  ✅ 添加12000点
  
  结果: NDT目标 = 静态A (50000点) + 动态A (12000点)
       ↑ 立即拥有历史累积的动态信息
```

## 5. 完整时序分析

### 5.1 典型一帧的完整流程（已累积动态层的情况）

```
时刻 T = 10.5秒
当前位置: (X=100.0, Y=200.0)
对应Grid: (10, 20)
假设已有动态层累积

┌────────────────────────────────────────────────────────────┐
│ Thread 1: 主定位线程                                         │
└────────────────────────────────────────────────────────────┘

1. Align(input_cloud) 被调用
   └─ current_time = 10.5
   
2. LoadOnPose(guess_pose)
   ├─ this_grid = (10, 20)
   ├─ 加载范围: load_map_size=2
   ├─ 卸载范围: unload_map_size=3
   │
   ├─ 检查需要加载的chunks:
   │  └─ Grid(10,20): 已加载
   │  └─ Grid(10,21): 需加载
   │     ├─ static_chunks_[(10,21)]->LoadCloud()  // 静态
   │     ├─ dynamic_chunks_.find((10,21)) == end
   │     └─ 创建 dynamic_chunks_[(10,21)]  // 动态（空）
   │        └─ dynamic_map_updated_ = true  ✓
   │
   └─ 检查需要卸载的chunks:
      └─ Grid(10,16): 距离=4 > 3
         ├─ loaded_chunks_.erase((10,16))
         ├─ map_updated_ = true  ✓
         └─ 策略处理:
            ├─ SHORT: cloud_=nullptr
            ├─ LONG: 无操作（保留在内存）
            └─ PERSISTENT: 可选存盘+清空

┌────────────────────────────────────────────────────────────┐
│ Thread 2: 地图更新线程 (10ms一检查)                           │
└────────────────────────────────────────────────────────────┘

3. UpdateMapThread 检测到变化
   ├─ map_->MapUpdated() = true  (静态地图变化)
   ├─ map_->DynamicMapUpdated() = true  (动态地图变化)
   └─ 调用 UpdateGlobalMap()

4. UpdateGlobalMap()
   └─ SetNewTargetForNDT(ndt)
      ├─ 清空旧目标
      ├─ 遍历 loaded_chunks_ = [(10,20), (10,21), (11,20), ...]
      │
      ├─ 添加静态层:
      │  ├─ ndt->AddTarget(static_chunks_[(10,20)]->cloud_)  // 50000点
      │  ├─ ndt->AddTarget(static_chunks_[(10,21)]->cloud_)  // 50000点
      │  └─ ... (共6个静态chunks)
      │
      ├─ 添加动态层:
      │  ├─ if (dynamic_chunks_[(10,20)]->cloud_ != nullptr)  ✓
      │  │  └─ ndt->AddTarget(dynamic_chunks_[(10,20)]->cloud_)  // 8000点
      │  ├─ if (dynamic_chunks_[(10,21)]->cloud_ != nullptr)  ✗ (刚创建)
      │  │  └─ 跳过
      │  └─ ... (只有部分有动态层)
      │
      └─ ndt->ComputeTargetGrids()
         └─ 融合: 6×50000静态点 + 3×8000动态点 = 324000点
            └─ 构建统一NDT网格 (1m分辨率)

┌────────────────────────────────────────────────────────────┐
│ Thread 1: 继续主定位线程                                      │
└────────────────────────────────────────────────────────────┘

5. Localize(pose_esti, score, input_cloud)
   ├─ ndt->setInputSource(input_cloud)  // 30000点
   ├─ ndt->align(*output, guess_pose)
   │  └─ NDT匹配: 30000点 vs 324000点NDT网格
   │     └─ 包含静态+动态融合信息
   ├─ score = 2.5  (高质量匹配)
   └─ loc_success = true

6. 更新条件检查
   ├─ loc_success = true  ✓
   ├─ score > 2.2  ✓
   ├─ distance > 5m 或 time > 10s  ✓
   └─ 调用 UpdateDynamicCloud()

7. UpdateDynamicCloud(cloud_world, true)
   ├─ 遍历当前scan的每个点
   ├─ 确定点所属grid
   └─ 添加到对应的dynamic_chunks_[grid]->cloud_
      ├─ dynamic_chunks_[(10,20)]->cloud_: 8000 → 8500点
      ├─ dynamic_chunks_[(10,21)]->cloud_: 0 → 500点 (首次累积)
      └─ dynamic_map_updated_ = true  ✓

┌────────────────────────────────────────────────────────────┐
│ 下一次循环 (10ms后)                                          │
└────────────────────────────────────────────────────────────┘

8. UpdateMapThread 再次检测
   └─ map_->DynamicMapUpdated() = true
      └─ UpdateGlobalMap()
         └─ SetNewTargetForNDT(ndt)
            └─ 使用更新后的动态层（8500点，500点）
               └─ NDT目标点数: 300000+500 = 300500点

结果: 动态层逐步累积，定位质量逐步提升
```

## 6. 重要结论

### 6.1 核心结论总结

1. **定位算法完全相同**
   - 所有策略都使用同一个`SetNewTargetForNDT()`函数
   - NDT匹配对静态层和动态层一视同仁
   - 没有任何策略相关的权重或优先级设置

2. **参与条件唯一**
   - 动态层是否参与定位，只取决于`cloud_是否非空`
   - 与策略类型无关

3. **策略差异仅在生命周期**
   - **SHORT**: 离开清空 → 再次进入重新累积
   - **LONG**: 会话内保留 → 重启后清空
   - **PERSISTENT**: 永久保留 → 跨会话累积

4. **定位质量的差异来源**
   - 不是算法差异，而是**动态层数据的丰富度**
   - SHORT: 单次会话累积 (薄)
   - LONG: 单次运行累积 (中)
   - PERSISTENT: 长期累积 (厚)

### 6.2 策略选择的本质

```
选择策略 = 选择动态层的累积策略

SHORT      → 不需要历史，每次重新适应
LONG       → 需要单次会话内的历史
PERSISTENT → 需要跨会话的长期历史
```

### 6.3 代码验证关键点

**验证点1**: SetNewTargetForNDT是否有策略分支？
```bash
grep -n "policy_" tiled_map.h
# 结果: 只在Options定义，SetNewTargetForNDT中无出现
```

**验证点2**: 动态层添加是否有条件？
```cpp
// tiled_map.h:224-229
if (dynamic_chunks_.find(idx) != dynamic_chunks_.end()) {
    if (dynamic_chunks_[idx]->cloud_ != nullptr) {  // 唯一条件
        ndt->AddTarget(dynamic_chunks_[idx]->cloud_);
    }
}
// 结论: 只检查非空，不检查策略
```

**验证点3**: LoadOnPose中策略检查的位置？
```cpp
// tiled_map.cc:333-354
// 只在卸载逻辑中出现
if (options_.policy_ == DynamicCloudPolicy::SHORT) { ... }
if (options_.policy_ == DynamicCloudPolicy::PERSISTENT) { ... }
// 加载逻辑中无策略检查
```

### 6.4 实际影响分析

| 方面 | 影响因素 | SHORT | LONG | PERSISTENT |
|------|---------|-------|------|------------|
| **首次进入精度** | 动态层数据量 | 低 (空) | 低 (空) | 高 (有历史) |
| **多次进入精度** | 累积程度 | 中 (单次) | 高 (单次) | 最高 (跨次) |
| **定位鲁棒性** | 动态信息丰富度 | 低 | 中 | 高 |
| **环境适应性** | 能否学习变化 | 弱 | 中 | 强 |
| **长期退化风险** | 陈旧数据累积 | 无 | 无 | 有 (需定期清理) |

### 6.5 最佳实践建议

1. **开发/测试阶段**
   ```yaml
   dyn_cloud_policy: short
   # 优点: 每次都是干净状态，便于调试
   # 缺点: 看不到长期效果
   ```

2. **单班次运行**
   ```yaml
   dyn_cloud_policy: long
   # 优点: 单次运行内充分利用累积
   # 缺点: 每天重启后重新开始
   ```

3. **生产环境**
   ```yaml
   dyn_cloud_policy: persistent
   save_dyn_when_quit: true
   save_dyn_when_unload: false  # 减少IO
   # 优点: 长期累积，定位质量持续提升
   # 维护: 每月检查动态层数据量
   ```

## 附录：关键函数调用链

```
每帧定位的完整调用链:

main_thread:
  Align(cloud)
    ├─> LoadOnPose(pose)
    │   ├─> static_chunks_[g]->LoadCloud()
    │   ├─> dynamic_chunks_.emplace(g, new_chunk)  (如不存在)
    │   └─> 策略相关的卸载处理
    │       ├─> SHORT: cloud_=nullptr
    │       ├─> LONG: 无操作
    │       └─> PERSISTENT: 存盘+可选清空
    │
    └─> Localize(pose, score, cloud)
        └─> ndt->align()  (使用当前NDT目标)

update_thread:
  UpdateMapThread() [每10ms]
    └─> if (MapUpdated() || DynamicMapUpdated())
        └─> UpdateGlobalMap()
            └─> SetNewTargetForNDT(ndt)  ← 无策略分支
                ├─> for (idx : loaded_chunks_)
                │   └─> ndt->AddTarget(static_chunks_[idx]->cloud_)
                ├─> for (idx : loaded_chunks_)
                │   └─> if (dynamic_chunks_[idx]->cloud_ != nullptr)  ← 唯一条件
                │       └─> ndt->AddTarget(dynamic_chunks_[idx]->cloud_)
                └─> ndt->ComputeTargetGrids()

main_thread (续):
  Align(cloud) 继续
    └─> if (update_condition)
        └─> UpdateDynamicCloud(cloud_world)
            └─> for (pt : cloud)
                └─> dynamic_chunks_[grid]->cloud_->push_back(pt)
                └─> dynamic_map_updated_ = true  (触发下次重建)
```
