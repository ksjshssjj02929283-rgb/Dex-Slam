## 1. 地图架构概述

### 1.1 双层地图设计

Lightning-LM采用**静态+动态**的双层地图架构，充分结合两者优势：

```
┌─────────────────────────────────────────┐
│          Lightning-LM 地图系统           │
├─────────────────────────────────────────┤
│                                         │
│  ┌──────────────┐    ┌──────────────┐ │
│  │  静态地图层   │    │  动态地图层   │ │
│  │  Static Map  │    │ Dynamic Map  │ │
│  ├──────────────┤    ├──────────────┤ │
│  │ • SLAM建图   │    │ • 实时累积   │ │
│  │ • 高质量     │    │ • 环境适应   │ │
│  │ • 不变       │    │ • 可更新     │ │
│  │ • 分块存储   │    │ • 分块存储   │ │
│  └──────────────┘    └──────────────┘ │
│           │                  │         │
│           └────────┬─────────┘         │
│                    ↓                   │
│           ┌────────────────┐           │
│           │   NDT匹配引擎   │           │
│           │  (融合使用)     │           │
│           └────────────────┘           │
│                                         │
└─────────────────────────────────────────┘
```

### 1.2 设计理念对比

| 特性 | 静态地图 | 动态地图 |
|------|---------|---------|
| **来源** | SLAM后端优化位姿 | 实时定位点云累积 |
| **质量** | 高（全局优化） | 中（定位精度依赖） |
| **更新** | 不更新 | 实时更新 |
| **作用** | 主要定位依据 | 补充静态地图，适应变化 |
| **存储** | PCD文件（永久） | 内存/PCD（可配置） |
| **生命周期** | 永久 | 短期/长期/永久（可配置） |

### 1.3 分块管理策略

两层地图都采用**100m × 100m Chunk**分块管理：

```
地图分块示例（俯视图）：

        -1        0        1        2
    ┌────────┬────────┬────────┬────────┐
  2 │Chunk   │Chunk   │Chunk   │Chunk   │
    │(-1,2)  │(0,2)   │(1,2)   │(2,2)   │
    ├────────┼────────┼────────┼────────┤
  1 │Chunk   │Chunk   │Chunk   │Chunk   │
    │(-1,1)  │(0,1)   │(1,1)   │(2,1)   │
    ├────────┼────────┼────────┼────────┤
  0 │Chunk   │Chunk   │Chunk   │Chunk   │ ← 车辆位置
    │(-1,0)  │(0,0)   │(1,0)   │(2,0)   │   
    ├────────┼────────┼────────┼────────┤
 -1 │Chunk   │Chunk   │Chunk   │Chunk   │
    │(-1,-1) │(0,-1)  │(1,-1)  │(2,-1)  │
    └────────┴────────┴────────┴────────┘
    
每个Chunk: 100m × 100m
```

**分块优势**：
- ✅ **内存优化**：按需加载，支持大规模地图
- ✅ **加载效率**：快速定位需要的Chunk
- ✅ **动态管理**：远离区域自动卸载
- ✅ **并行处理**：独立Chunk可并行操作

## 2. 静态地图

### 2.1 静态地图生成

#### 2.1.1 生成流程

```
[SLAM建图模式]
    ↓
关键帧点云 + 后端优化位姿
    ↓
ConvertFromFullPCD()
    ├─ 遍历全局点云
    ├─ 按位置分配到Chunk
    └─ 每个Chunk内体素化
    ↓
SaveToBin()
    ├─ 保存index.txt（索引文件）
    ├─ 保存各Chunk的PCD文件
    └─ 保存功能点信息
    ↓
[静态地图文件]
```

#### 2.1.2 代码实现

```cpp
bool TiledMap::ConvertFromFullPCD(CloudPtr map, const SE3& start_pose, 
                                  const std::string& map_path) {
    origin_.setZero();
    options_.map_path_ = map_path;
    
    // 添加起点作为功能点
    func_points_.emplace_back(FunctionalPoint("start", start_pose));
    
    chunk_id_ = 0;
    
    // 遍历全局点云，分配到对应Chunk
    for (const auto& pt : map->points) {
        Vec2i grid = Pos2Grid(math::ToEigen<float, 2, PointType>(pt));
        
        auto iter = static_chunks_.find(grid);
        if (iter != static_chunks_.end()) {
            // Chunk已存在，添加点
            iter->second->AddPoint(pt);
        } else {
            // 创建新Chunk
            int id = chunk_id_;
            auto new_chunk = std::make_shared<MapChunk>(id, grid, "");
            static_chunks_.emplace(grid, new_chunk);
            id_to_grid_.emplace(id, grid);
            chunk_id_++;
        }
    }
    
    // 保存到文件
    SaveToBin(false);
    return true;
}
```

**关键函数**：`Pos2Grid()` - 世界坐标到Grid索引的转换

```cpp
Vec2i Pos2Grid(const Vec2d& pos) {
    // chunk_size_ = 100.0, inv_chunk_size_ = 0.01
    int x = floor(pos.x() * inv_chunk_size_);
    int y = floor(pos.y() * inv_chunk_size_);
    return Vec2i(x, y);
}
```

**坐标映射示例**：
```
世界坐标 (150.5, 250.8) → Grid (1, 2)
世界坐标 (-50.2, 80.6)  → Grid (-1, 0)
世界坐标 (0.1, 0.1)     → Grid (0, 0)
世界坐标 (-0.1, -0.1)   → Grid (-1, -1)
```

#### 2.1.3 保存格式

**文件结构**：
```

├── index.txt              # 地图索引（核心文件）
├── 0.pcd                  # Chunk 0 的点云
├── 1.pcd                  # Chunk 1 的点云

├── ...
```

**保存代码**：
```cpp
void TiledMap::SaveToBin(bool only_dynamic) {
    if (!only_dynamic) {
        // 保存静态地图索引
        std::ofstream fout(options_.map_path_ + "/index.txt");
        
        // 1. 写入原点
        fout << std::setprecision(18) 
             << origin_[0] << " " << origin_[1] << " " << origin_[2] << "\n";
        
        // 2. 写入各Chunk信息
        for (auto& cp : static_chunks_) {
            if (cp.second->cloud_->empty()) continue;
            
            std::string filename = options_.map_path_ + "/" + 
                                  std::to_string(cp.second->id_) + ".pcd";
            
            // 体素化并压缩保存
            pcl::io::savePCDFileBinaryCompressed(
                filename, 
                *math::VoxelGrid(cp.second->cloud_, 
                                options_.voxel_size_in_chunk_));  // 0.1m
            
            fout << cp.second->id_ << " " 
                 << cp.first[0] << " " << cp.first[1] << " " 
                 << filename << "\n";
        }
        
        // 3. 写入功能点
        fout << "# functional points\n";
        for (const auto& fp : func_points_) {
            auto t = fp.pose_.translation();
            auto q = fp.pose_.unit_quaternion();
            fout << fp.name_ << " " 
                 << t[0] << " " << t[1] << " " << t[2] << " "
                 << q.x() << " " << q.y() << " " << q.z() << " " << q.w() << "\n";
        }
    }
}
```

### 2.2 静态地图加载

#### 2.2.1 加载策略

静态地图采用**索引先行，按需加载**策略：

```
启动时：
    LoadMapIndex()
    └─ 仅加载index.txt
       ├─ 解析地图原点
       ├─ 解析Chunk索引（不加载点云）
       └─ 解析功能点

定位初始化时：
    LoadOnPose(fp_pose)
    └─ 加载功能点附近的Chunk点云

运行时：
    LoadOnPose(current_pose)  // 每帧调用
    └─ 动态加载/卸载Chunk
```

#### 2.2.2 索引加载

```cpp
bool TiledMap::LoadMapIndex() {
    std::ifstream fin(options_.map_path_ + "/index.txt");
    if (!fin) {
        LOG(ERROR) << "cannot load map index from: " << options_.map_path_;
        return false;
    }
    
    ClearMap();
    bool first_line = true;
    bool reading_fp = false;
    
    while (!fin.eof()) {
        std::string line;
        std::getline(fin, line);
        
        if (line.empty()) continue;
        
        std::stringstream ss(line);
        
        // 第一行：读取原点
        if (first_line) {
            ss >> origin_[0] >> origin_[1] >> origin_[2];
            first_line = false;
            continue;
        }
        
        // 功能点标记
        if (line == "# functional points") {
            reading_fp = true;
            continue;
        }
        
        // 读取功能点
        if (reading_fp) {
            std::string name;
            double data[7];  // x,y,z,qx,qy,qz,qw
            ss >> name;
            for (int i = 0; i < 7; ++i) ss >> data[i];
            
            func_points_.emplace_back(
                name,
                SE3(Quatd(data[6], data[3], data[4], data[5]),  // qw,qx,qy,qz
                    Vec3d(data[0], data[1], data[2])));
        } else {
            // 读取Chunk索引（不加载点云）
            int id;
            Vec2i grid;
            std::string path;
            ss >> id >> grid[0] >> grid[1] >> path;
            
            // 修正路径为配置文件中的路径
            path = options_.map_path_ + "/" + std::to_string(id) + ".pcd";
            
            // 创建Chunk对象（此时不加载点云）
            auto ck = std::make_shared<MapChunk>(id, grid, path);
            static_chunks_.emplace(grid, ck);
            id_to_grid_.emplace(id, grid);
            
            if (id > chunk_id_) {
                chunk_id_ = id;
            }
        }
    }
    
    LOG(INFO) << "loaded chunks: " << static_chunks_.size() 
              << ", fps: " << func_points_.size();
    
    return true;
}
```

**关键**：
- ✅ 只加载索引，不加载点云数据
- ✅ 建立 `id → grid` 和 `grid → chunk` 映射
- ✅ 快速启动，内存占用小

#### 2.2.3 动态加载/卸载

```cpp
void TiledMap::LoadOnPose(const SE3& pose) {
    Vec2d p = pose.translation().head<2>();
    auto this_grid = Pos2Grid(p);
    
    // 如果当前Grid没变，不需要重新加载
    if (last_load_grid_set_ && last_load_grid_ == this_grid) {
        map_updated_ = false;
        return;
    }
    
    // ===== 加载近邻Chunk =====
    for (const auto& cp : static_chunks_) {
        Vec2i d = cp.first - this_grid;
        int manhattan_dist = abs(d[0]) + abs(d[1]);  // 曼哈顿距离
        
        if (manhattan_dist <= options_.load_map_size_) {  // 默认2
            if (loaded_chunks_.find(cp.first) == loaded_chunks_.end()) {
                // 未加载，现在加载
                map_updated_ = true;
                
                if (cp.second->cloud_ == nullptr) {
                    cp.second->LoadCloud();  // 从硬盘读取PCD
                }
                
                loaded_chunks_.emplace(cp.first);
            }
            
            // 同时创建对应的动态层Chunk
            auto dyn_iter = dynamic_chunks_.find(cp.first);
            if (dyn_iter == dynamic_chunks_.end()) {
                auto new_chunk = std::make_shared<MapChunk>(
                    cp.second->id_, cp.first,
                    options_.map_path_ + "/" + std::to_string(cp.second->id_) + "_dyn.pcd");
                dynamic_chunks_.emplace(cp.first, new_chunk);
                dynamic_map_updated_ = true;
            }
        }
    }
    
    // ===== 卸载过远Chunk =====
    for (auto iter = loaded_chunks_.begin(); iter != loaded_chunks_.end();) {
        Vec2i g = *iter;
        Vec2i d = g - this_grid;
        int manhattan_dist = abs(d[0]) + abs(d[1]);
        
        if (manhattan_dist > options_.unload_map_size_) {  // 默认3
            map_updated_ = true;
            iter = loaded_chunks_.erase(iter);
            
            // 根据动态层策略处理
            auto d_iter = dynamic_chunks_.find(g);
            if (options_.policy_ == DynamicCloudPolicy::SHORT && 
                d_iter != dynamic_chunks_.end()) {
                // SHORT策略：直接清空动态层
                dynamic_chunks_[g]->cloud_ = nullptr;
                dynamic_map_updated_ = true;
            }
            
            if (options_.policy_ == DynamicCloudPolicy::PERSISTENT && 
                d_iter != dynamic_chunks_.end() && d_iter->second->loaded_) {
                // PERSISTENT策略：存盘后卸载
                if (options_.save_dyn_when_unload_ && 
                    d_iter->second->cloud_ != nullptr &&
                    !d_iter->second->cloud_->empty()) {
                    
                    std::string filename = options_.map_path_ + "/" + 
                                          std::to_string(d_iter->second->id_) + "_dyn.pcd";
                    pcl::io::savePCDFileBinaryCompressed(filename, *d_iter->second->cloud_);
                }
                
                if (options_.delete_when_unload_) {
                    d_iter->second->Unload();
                }
            }
        } else {
            iter++;
        }
    }
    
    last_load_grid_ = this_grid;
    last_load_grid_set_ = true;
}
```

**加载范围可视化** (当前位置在 Grid (0,0))：

```
load_map_size = 2 (加载范围)
unload_map_size = 3 (卸载范围)

      -3  -2  -1   0   1   2   3
    ┌───┬───┬───┬───┬───┬───┬───┐
  3 │   │   │ U │ L │ U │   │   │  U: 卸载范围
    ├───┼───┼───┼───┼───┼───┼───┤  L: 加载范围
  2 │   │ U │ L │ L │ L │ U │   │  C: 当前位置
    ├───┼───┼───┼───┼───┼───┼───┤
  1 │ U │ L │ L │ L │ L │ L │ U │
    ├───┼───┼───┼───┼───┼───┼───┤
  0 │ L │ L │ L │ C │ L │ L │ L │ ← 车辆
    ├───┼───┼───┼───┼───┼───┼───┤
 -1 │ U │ L │ L │ L │ L │ L │ U │
    ├───┼───┼───┼───┼───┼───┼───┤
 -2 │   │ U │ L │ L │ L │ U │   │
    ├───┼───┼───┼───┼───┼───┼───┤
 -3 │   │   │ U │ L │ U │   │   │
    └───┴───┴───┴───┴───┴───┴───┘

曼哈顿距离计算：
  - Grid (0,2): |0-0| + |2-0| = 2 (加载)
  - Grid (1,1): |1-0| + |1-0| = 2 (加载)
  - Grid (2,2): |2-0| + |2-0| = 4 (超出范围)
  - Grid (0,3): |0-0| + |3-0| = 3 (卸载范围边界)
```

### 2.3 MapChunk 结构

```cpp
struct MapChunk {
    int id_ = 0;                  // Chunk唯一ID
    Vec2i grid_ = Vec2i::Zero();  // 所属Grid坐标
    std::string filename_;        // PCD文件路径
    bool loaded_ = false;         // 是否已加载到内存
    CloudPtr cloud_ = nullptr;    // 点云数据
    std::mutex data_mutex_;       // 数据访问锁
    
    // 加载点云
    void LoadCloud() {
        if (filename_.empty() || !PathExists(filename_)) {
            return;
        }
        
        std::lock_guard<std::mutex> lock(data_mutex_);
        cloud_.reset(new PointCloudType);
        pcl::io::loadPCDFile(filename_, *cloud_);
        loaded_ = true;
    }
    
    // 卸载点云
    void Unload() {
        std::lock_guard<std::mutex> lock(data_mutex_);
        cloud_ = nullptr;
        loaded_ = false;
    }
    
    // 添加点
    void AddPoint(const PointType& pt) {
        std::lock_guard<std::mutex> lock(data_mutex_);
        if (cloud_ == nullptr) {
            cloud_.reset(new PointCloudType);
        }
        cloud_->push_back(pt);
    }
};
```

## 3. 动态地图

### 3.1 动态地图设计

#### 3.1.1 设计目标

动态地图解决以下问题：

1. **环境变化适应**：停车场车辆变化、路边障碍物等
2. **地图补充**：静态地图可能遗漏的区域
3. **精度提升**：在静态地图基础上增加细节

#### 3.1.2 三种策略

```cpp
enum class DynamicCloudPolicy {
    SHORT,       // 短期保留
    LONG,        // 长期保留
    PERSISTENT   // 永久保留
};
```

| 策略 | 生命周期 | 存盘 | 下次加载 | 适用场景 |
|------|---------|------|---------|---------|
| **SHORT** | 车辆离开后清空 | ❌ | ❌ | 测试、临时运行 |
| **LONG** | 保留在内存 | ❌ | ❌ | 单次长时间运行 |
| **PERSISTENT** | 永久保留 | ✅ | ✅ | 生产环境（推荐）|

**配置示例**：
```yaml
tiled_map:
  dyn_cloud_policy: persistent      # short/long/persistent
  load_dyn_cloud: true              # 启动时加载动态层
  save_dyn_when_quit: true          # 退出时保存
  save_dyn_when_unload: true        # 卸载时保存
  delete_when_unload: false         # 卸载时是否清空内存
  max_pts_in_dyn_chunk: 50000       # 每个动态Chunk最大点数
```

### 3.2 动态地图生成

#### 3.2.1 更新触发条件

```cpp
// 在lidar_loc.cc中的更新逻辑
bool should_update = 
    options_.update_dynamic_cloud_ &&           // 功能开启
    loc_success &&                              // 定位成功
    (distance > options_.update_kf_dis_ ||      // 距离间隔（默认5m）
     time_diff > options_.update_kf_time_) &&   // 时间间隔（默认10s）
    score > options_.update_lidar_loc_score_;   // 分值足够高（默认2.2）

if (should_update) {

}
```

**更新条件可视化**：
```

定位帧:  ●───●───●───●───●───●───●───●───●
         │   │   │   │   │   │   │   │   │
```

#### 3.2.2 核心更新逻辑

```cpp
void TiledMap::UpdateDynamicCloud(CloudPtr cloud_world, bool remove_old) {
    std::set<Vec2i, math::less_vec<2>> updated_grids;  // 记录更新的Grid
    
    UL lock(dynamic_data_mutex_);
    
    for (auto& pt : cloud_world->points) {
        // 检查是否在动态区域内（如果配置了动态多边形）
        if (FallsInDynamicArea(pt.getVector3fMap()) < 0) {
            continue;
        }
        
        dynamic_map_updated_ = true;
        
        // 确定点所属的Grid
        Vec2i grid = Pos2Grid(math::ToEigen<float, 2, PointType>(pt));
        
        auto iter = dynamic_chunks_.find(grid);
        auto iter_static = static_chunks_.find(grid);
        
        if (iter != dynamic_chunks_.end()) {
            // 动态Chunk已存在
            if (!iter->second->loaded_) {
                iter->second->LoadCloud();
                continue;
            }
            
            // 检查是否已满
            if (!remove_old && 
                iter->second->cloud_->size() >= options_.max_pts_in_dyn_chunk_) {
                continue;  // 满了就不再添加
            }
            
            iter->second->AddPoint(pt);
            updated_grids.emplace(grid);
            
        } else {
            // 动态Chunk不存在，创建新的
            if (iter_static != static_chunks_.end()) {
                // 对应的静态Chunk存在
                
                if (options_.policy_ == DynamicCloudPolicy::SHORT) {
                    // SHORT策略：检查是否在卸载范围内
                    Vec2i d = last_load_grid_ - grid;
                    int n = abs(d[0]) + abs(d[1]);
                    if (n > options_.unload_map_size_) {
                        continue;  // 太远了，不创建
                    }
                }
                
                // 使用与静态Chunk相同的ID
                int id = iter_static->second->id_;
                auto new_chunk = std::make_shared<MapChunk>(
                    id, grid, 
                    options_.map_path_ + "/" + std::to_string(id) + "_dyn.pcd");
                    
                new_chunk->AddPoint(pt);
                dynamic_chunks_.emplace(grid, new_chunk);
                updated_grids.emplace(grid);
            }
        }
    }
    
    // 后处理：防止Chunk过大
    for (const auto& g : updated_grids) {
        size_t full_size = dynamic_chunks_[g]->cloud_->size();
        
        // 超过1.5倍上限，体素化降采样
        if (full_size > 1.5 * options_.max_pts_in_dyn_chunk_) {
            dynamic_chunks_[g]->cloud_ = 
                math::VoxelGrid(dynamic_chunks_[g]->cloud_, 0.5);
        }
        
        // 超过上限且需要移除旧点，随机删除70%旧点
        if (remove_old && full_size > options_.max_pts_in_dyn_chunk_) {
            size_t remove_cnt = size_t(0.7 * full_size);
            dynamic_chunks_[g]->cloud_->points.erase(
                dynamic_chunks_[g]->cloud_->points.begin(),
                dynamic_chunks_[g]->cloud_->points.begin() + remove_cnt);
            dynamic_chunks_[g]->cloud_->width = full_size - remove_cnt;
            dynamic_chunks_[g]->cloud_->points.shrink_to_fit();
        }
    }
}
```

**点数控制策略**：
```
正常状态:
  0 ─────────────► 50,000 点
                   ▲
                   └─ max_pts_in_dyn_chunk

超限处理:
  50,000 ─────► 75,000 ─────► 体素化降采样
                ▲            (0.5m分辨率)
                └─ 1.5倍阈值

  50,000 ─────► 移除70%旧点 ─────► 15,000点
                (保留30%新点)
```

```cpp
void TiledMap::ResetDynamicCloud() {

    // 清空所有动态Chunk

    dynamic_grids_.clear();
    
    if (options_.policy_ == DynamicCloudPolicy::PERSISTENT) {
        // PERSISTENT策略：重新加载历史动态层
        int loaded_cnt = 0;
        for (auto it = id_to_grid_.begin(); it != id_to_grid_.end(); it++) {

            Vec2i grid = it->second;

                if (options_.load_dyn_cloud_) {
                    dyn_chunk->LoadCloud();
                    loaded_cnt++;
                }
            }
        }
        
        if (loaded_cnt > 0) {
            LOG(INFO) << "reset dynamic map success, load size: " << loaded_cnt;
        }
    }
```

```cpp
CloudPtr TiledMap::GetAllMap() {
    CloudPtr cloud(new PointCloudType);
    cloud->reserve(100000 * 25);
    
    // 1. 获取静态地图
    {
        UL lock(static_data_mutex_);
        for (auto& idx : loaded_chunks_) {
            *cloud += *static_chunks_[idx]->cloud_;
        }

    // 2. 叠加动态地图

        for (auto& idx : loaded_chunks_) {

                if (dynamic_chunks_[idx]->cloud_ != nullptr) {
                    *cloud += *dynamic_chunks_[idx]->cloud_;
                }
            }
        }
    }
    
    return cloud;
}
```

### 5.2 性能调优

#### 5.2.1 地图大小 vs 内存

```

  静态层：约 2-5 MB (取决于点云密度)

  load_map_size=2: 25 chunks →  约 75-200 MB
  load_map_size=3: 49 chunks →  约 150-400 MB
```

#### 5.2.2 更新频率 vs CPU

```
动态层更新开销：
  - 点云过滤：5-10ms
  - 坐标变换：5-10ms
  - 添加到Chunk：1-3ms
  - 总计：约 10-20ms/帧

建议：
  - 高速场景：update_kf_dis = 10m, update_kf_time = 20s
  - 低速场景：update_kf_dis = 3m, update_kf_time = 5s

```

#### 5.2.3 NDT重建频率

```
地图更新 ──► NDT重建 ──► 开销：50-200ms

优化：
  1. 增大load_map_size和unload_map_size的差值
     → 减少频繁加载/卸载
     
  2. 降低车速附近的更新频率

  3. UpdateMapThread独立线程
```
