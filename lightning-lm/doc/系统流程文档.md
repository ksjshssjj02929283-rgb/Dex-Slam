# Lightning-LM 系统流程文档

## 1. 系统架构概览

Lightning-LM采用模块化设计，主要包含以下核心模块：

```
┌─────────────────────────────────────────────────────────────┐
│                    Lightning-LM System                       │
├─────────────────────────────────────────────────────────────┤
│  传感器输入层                                                  │
│  ├─ IMU数据流                                                │
│  └─ LiDAR点云数据流（Livox/Velodyne/Ouster）                  │
├─────────────────────────────────────────────────────────────┤
│  核心处理层                                                    │
│  ├─ LIO前端 (LaserMapping)                                   │
│  ├─ 回环检测 (LoopClosing)                                   │
│  ├─ 定位模块 (Localization)                                  │
│  ├─ 地图管理 (TiledMap)                                      │
│  └─ 2D栅格转换 (G2P5)                                        │
├─────────────────────────────────────────────────────────────┤
│  输出层                                                       │
│  ├─ TF位姿输出                                               │
│  ├─ 3D/2D地图                                                │
│  ├─ UI可视化                                                 │
│  └─ ROS2话题/服务                                            │
└─────────────────────────────────────────────────────────────┘
```

## 2. 建图（SLAM）Pipeline

### 2.1 SLAM系统整体流程

```
[传感器数据] → [预处理] → [LIO前端] → [关键帧管理] → [地图保存]
                                ↓
                         [回环检测与优化]
                                ↓
                         [2D地图生成]
```

### 2.2 详细处理流程

#### 阶段1: 数据输入与预处理

```
IMU数据                    LiDAR点云
   ↓                          ↓
IMU缓冲队列 ←────────→ 点云预处理模块
   ↓                    (PointCloudPreprocess)
   ↓                          ↓
   └──────────→ 去畸变 & 时间同步 ←─────┘
                      ↓
                 预处理后点云
```

**关键步骤：**
1. **IMU预积分**: 
   - 接收原始IMU数据
   - 进行预积分计算
   - 更新状态估计

2. **点云预处理**:
   - 根据LiDAR类型解析点云（Livox/Velodyne/Ouster）
   - 提取每个点的时间戳
   - 应用时间缩放因子（`time_scale`）
   - 去除盲区内的点（`blind`参数）
   - 点云降采样（`point_filter_num`）

3. **时间同步**:
   - 将点云时间戳与IMU时间戳对齐
   - 确保数据时序一致性

#### 阶段2: LIO前端处理

```
[预处理点云 + IMU数据]
         ↓
    IVox3D建图
         ↓
    ESKF状态估计 ←─→ Anderson加速
         ↓
    点云去畸变
         ↓
    位姿优化 (迭代最多6次)
         ↓
    [输出：位姿 + 去畸变点云]
```

**核心组件：**

1. **IVox3D体素地图**:
   - 增量式体素网格
   - 快速最近邻搜索
   - 动态更新局部地图

2. **ESKF（误差状态卡尔曼滤波）**:
   - 状态向量: [位置, 速度, 姿态, 加速度偏置, 陀螺仪偏置]
   - 预测步: 使用IMU预积分
   - 更新步: 使用点到面距离约束

3. **Anderson加速** (可选):
   - 加速迭代收敛
   - 减少计算时间
   - 通过 `use_aa` 参数控制

4. **迭代优化**:
   ```
   For i = 1 to max_iteration (默认6次):
       1. 查找点云对应关系（IVox3D）
       2. 构建点到面约束
       3. 更新状态估计（ESKF）
       4. 检查收敛条件
   ```

**输出：**
- 当前帧位姿 `T_world_lidar`
- 去畸变后的点云
- 导航状态（位置、速度、姿态）

#### 阶段3: 关键帧判定与管理

```
[当前帧位姿]
      ↓
关键帧条件判断:
  - 平移距离 > kf_dis_th (默认2.0m)
  - 旋转角度 > kf_angle_th (默认15度)
      ↓
    [是] → 创建关键帧
              ↓
         关键帧内容:
           - ID
           - 时间戳
           - 位姿 T_world_lidar
           - 去畸变点云
           - 降采样点云
              ↓
         添加到关键帧列表
              ↓
         [触发后续处理]
```

#### 阶段4: 回环检测（可选）

```
[新关键帧] → [检测触发条件]
                  ↓
           每N个关键帧检测一次
           (loop_kf_gap = 20)
                  ↓
           [候选回环搜索]
              - ID间隔 > min_id_interval
              - 距离 < max_range
                  ↓
           [NDT配准验证]
              - 计算相对位姿
              - 评估匹配分数
                  ↓
           [回环确认]
           (score < ndt_score_th)
                  ↓
           [位姿图优化]
              - 添加回环约束
              - 优化所有关键帧位姿
              - 更新地图
                  ↓
           [回调通知]
```

**回环检测详细步骤：**

1. **候选回环检测**:
   ```
   For each 历史关键帧 kf_history:
       if (current_id - kf_history.id > closest_id_th):
           if (distance(current, kf_history) < max_range):
               添加到候选列表
   ```

2. **NDT配准**:
   - 使用历史关键帧点云构建NDT网格
   - 将当前关键帧点云配准到历史帧
   - 计算配准得分和相对位姿

3. **位姿图优化**:
   ```
   图节点: 所有关键帧位姿
   图边:
     - 相邻帧的相对位姿（里程计边）
     - 回环帧的相对位姿（回环边）
   
   优化目标:
     minimize Σ ||e_odom||² + Σ ||e_loop||²
   ```

#### 阶段5: 2D栅格地图生成（G2P5）

```
[3D关键帧点云]
       ↓
   地面估计 (可选)
       ↓
   高度过滤
    - min_th_floor 到 max_th_floor
       ↓
   投影到2D平面
       ↓
   栅格化 (grid_map_resolution)
       ↓
   占据概率更新
       ↓
   [2D栅格地图 (.pgm)]
```

**G2P5处理流程：**

1. **地面高度估计** (如果 `esti_floor=true`):
   - RANSAC拟合地面平面
   - 更新地面高度参数

2. **高度过滤**:
   ```
   For each 点 p in 点云:
       height = p.z - floor_height
       if (min_th_floor < height < max_th_floor):
           保留该点
   ```

3. **栅格化**:
   - 将3D点投影到2D网格
   - 更新每个网格的占据概率
   - 生成灰度值（0=占据，255=空闲，127=未知）

#### 阶段6: 地图保存

```
[保存触发]
    ↓
分块保存点云
  - 按空间位置划分chunks
  - 保存为 chunk_x_y.pcd
    ↓
生成完整地图
  - global.pcd (可视化用)
    ↓
保存2D地图
  - map.pgm
  - map.yaml
    ↓
保存关键帧信息
  - keyframes.txt (ID, 位姿)
```

### 2.4 在线与离线模式差异

**离线模式 (run_slam_offline)**:
- 单线程顺序处理
- 遍历整个数据包
- 处理完毕自动保存
- 适合调试和批量处理

**在线模式 (run_slam_online)**:
- 多线程并发处理
- 异步消息队列
- 动态跳帧（根据负载）
- 实时响应传感器数据
- 手动保存地图（ROS服务）

## 3. 定位（Localization）Pipeline

### 3.1 定位系统整体流程

```
[地图加载] → [初始化] → [LiDAR里程计] → [地图匹配] → [位姿优化] → [高频输出]
                                                    ↑
                                                    └─[动态层更新]
```

### 3.2 详细处理流程

#### 阶段1: 地图加载与初始化

```
[系统启动]
    ↓
加载地图配置
  - 读取 map_path
  - 加载地图元数据
    ↓
分块地图管理器初始化
  - 创建 TiledMap
  - 设置加载/卸载参数
    ↓
加载初始地图块
  - 根据初始位置
  - 加载周围 load_map_size 范围的chunks
    ↓
[可选] 加载动态层
  - 如果 load_dyn_cloud=true
    ↓
等待传感器数据
```

**TiledMap分块加载机制：**
```
当前位置
    ↓
计算所在chunk坐标 (x, y)
    ↓
加载范围: [x-load_map_size, x+load_map_size] × [y-load_map_size, y+load_map_size]
    ↓
卸载范围: 超出 unload_map_size 的chunks
    ↓
动态更新已加载chunks列表
```

#### 阶段2: LiDAR里程计（Lidar Odom）

```
[IMU + LiDAR数据]
    ↓
预处理 (同SLAM模式)
    ↓
IVox3D局部建图
    ↓
ESKF位姿估计
    ↓
输出: T_odom_lidar
  (相对于初始位置的里程计位姿)
```

**作用：**
- 提供帧间相对运动估计
- 用于位姿外推（extrapolation）
- 辅助地图匹配初值

**处理频率：**
- 可跳帧处理（`enable_lidar_odom_skip`）
- 跳帧数量: `lidar_odom_skip_num`

#### 阶段3: 地图匹配（Lidar Loc）

```
[当前扫描 + 全局地图]
    ↓
初值估计
  - 上一帧位姿 + 里程计增量
    ↓
[可选] 网格搜索
  - 角度范围: grid_search_angle_range
  - 角度步长: grid_search_angle_step
    ↓
NDT/ICP配准
  - 当前扫描 vs 全局地图
    ↓
评估匹配质量
  - 计算匹配得分
  - 检查收敛性
    ↓
输出: T_world_lidar
  (全局地图坐标系下的位姿)
```

**初始化定位 (首次定位)**:
```
if (init_with_fp == true):
    使用快速点云配准
    ↓
    多假设验证
    ↓
    选择最佳匹配
    (confidence > min_init_confidence)
else:
    使用给定初始位姿
```

**地图匹配详细步骤：**

1. **构建局部地图**:
   ```
   从TiledMap提取当前位置周围的点云
   ↓
   [可选] 分离静态层和动态层
   ↓
   构建NDT/IVox结构
   ```

2. **配准迭代**:
   ```
   For i = 1 to max_iterations:
       1. 变换当前扫描到地图坐标系
       2. 查找最近邻对应
       3. 计算残差
       4. 更新位姿增量
       5. 检查收敛
   ```

3. **质量评估**:
   ```
   计算指标:
     - 匹配得分 (score)
     - 内点比例
     - 协方差矩阵
   
   判断:
     if (score < update_lidar_loc_score):
         接受定位结果
     else:
         标记为低质量/失败
   ```

**处理频率：**
- 可跳帧处理（`enable_lidar_loc_skip`）
- 跳帧数量: `lidar_loc_skip_num`（默认4，即每5帧处理1次）

#### 阶段4: 位姿图优化（PGO）

```
[定位结果序列]
    ↓
构建位姿图
  节点: 定位位姿
  边: 
    - 里程计约束
    - 地图匹配约束
    ↓
增量式优化
  - 使用miao优化库
  - 仅优化窗口内节点
    ↓
平滑输出
  - 应用平滑因子
    ↓
输出: 优化后的位姿序列
```

**PGO处理：**

1. **图节点**:
   - 每个关键时刻的位姿

2. **图边类型**:
   - **里程计边**: 相邻帧的相对运动
     - 噪声: `dr_pos_noise`, `dr_ang_noise`
   - **定位边**: 地图匹配的绝对位姿
     - 噪声: `lidar_loc_pos_noise`, `lidar_loc_ang_noise`

3. **优化窗口**:
   - 固定大小的滑动窗口
   - 仅优化最近N个节点
   - 保持计算实时性

4. **异常检测**:
   ```
   For each 定位结果:
       残差 = ||优化位姿 - 定位位姿||
       if (残差 > lidar_loc_outlier_th):
           标记为异常值
           降低权重或移除约束
   ```

#### 阶段5: 位姿外推与平滑

```
[优化后位姿 + IMU数据]
    ↓
PoseExtrapolator (位姿外推器)
  - 使用IMU积分
  - 预测当前时刻位姿
    ↓
PoseSmoother (平滑器)
  - 融合外推位姿和优化位姿
  - 应用平滑因子
    ↓
高频输出 (100Hz)
  - 与IMU同频
```

**外推器工作原理：**
```
已知: 
  - t0时刻的优化位姿 T0
  - t0到t1之间的IMU数据

外推:
  T1_predicted = T0 * IMU_integration(t0, t1)
```

**平滑器工作原理：**
```
输入:
  - 外推位姿 T_extrap (高频)
  - 优化位姿 T_opt (低频但更准确)

输出:
  T_smooth = (1 - α) * T_extrap + α * T_opt
  
其中 α = smooth_factor (默认0.01)
```

#### 阶段6: 动态层管理

```
[当前帧观测]
    ↓
检测动态点
  - 与静态地图对比
  - 距离阈值判断
    ↓
更新动态层
  - 添加新观测
  - 更新点云时间戳
    ↓
动态层策略
  - 短期: 保留10秒内的点
  - 中期: 保留1分钟内的点
  - 永久: 一直保留
    ↓
[可选] 动态区域标记
    ↓
保存动态层
  - 退出时保存
  - 卸载地图块时保存
```

**动态点检测：**
```
For each 点 p in 当前扫描:
    nearest_static = query_static_map(p)
    if (distance(p, nearest_static) > threshold):
        标记为动态点
        添加到动态层
```

**动态层策略实现：**
```
if (policy == "short_term"):
    清除时间戳 < (current_time - 10s) 的点
elif (policy == "mid_term"):
    清除时间戳 < (current_time - 60s) 的点
else:  # persistent
    保留所有动态点
```

#### 阶段7: TF发布与输出

```
[最终位姿]
    ↓
坐标变换
  T_world_body = T_world_lidar * T_lidar_body
    ↓
发布TF
  - frame: map
  - child_frame: base_link
  - frequency: 100Hz
    ↓
[可选] 发布其他话题
  - 定位状态
  - 点云 (body/world坐标系)
```

### 3.4 定位关键特性

**1. 分块地图加载**
- 仅加载当前位置周围的地图块
- 动态加载/卸载，适应大场景
- 减少内存占用和计算量

**2. 动态跳帧处理**
- Lidar Odom: 轻量级，可高频运行
- Lidar Loc: 计算密集，可跳帧
- 根据计算资源自适应调整

**3. 动静态分离**
- 静态层: 建图时的静态环境
- 动态层: 运行时的动态变化
- 提高动态场景下的定位鲁棒性

**4. 高频平滑输出**
- IMU外推: 100Hz高频预测
- 定位优化: 低频但准确
- 平滑融合: 兼顾实时性和精度

## 4. 线程模型

### 4.1 SLAM系统线程

**在线模式：**
```
主线程
  ├─ ROS2 Spin (消息接收)
  └─ UI渲染

LIO线程
  └─ 点云处理 + 状态估计

回环检测线程
  ├─ 候选检测
  ├─ NDT配准
  └─ 位姿图优化

G2P5线程
  └─ 2D地图生成

保存线程
  └─ 地图保存（按需触发）
```

**离线模式：**
```
主线程
  ├─ 数据包读取
  ├─ 顺序处理
  │   ├─ LIO
  │   ├─ 回环检测
  │   └─ G2P5
  └─ 地图保存
```

### 4.2 定位系统线程

**在线模式：**
```
主线程
  └─ ROS2 Spin (消息接收)

Lidar Odom线程
  └─ 里程计估计 (高频)

Lidar Loc线程
  └─ 地图匹配 (低频)

PGO线程
  ├─ 位姿图优化
  └─ 平滑输出

TF发布线程
  └─ 高频TF发布 (100Hz)

地图管理线程
  ├─ 地图块加载/卸载
  └─ 动态层更新
```

## 5. 性能优化策略

### 5.1 计算优化

1. **IVox3D增量式地图**
   - 避免全局地图重建
   - O(1)复杂度的点云插入

2. **Anderson加速**
   - 减少迭代次数
   - 加速收敛速度

3. **点云降采样**
   - 减少点数
   - 保持特征完整性

4. **动态跳帧**
   - 根据负载自适应
   - 保证实时性

### 5.2 内存优化

1. **分块地图存储**
   - 按需加载/卸载
   - 减少内存峰值

2. **关键帧管理**
   - 仅保留必要信息
   - 定期清理历史数据

3. **点云压缩**
   - 降采样后保存
   - 减少存储空间

### 5.3 并发优化

1. **异步消息处理**
   - 多线程并发
   - 消息队列缓冲

2. **计算任务分离**
   - 主要计算独立线程
   - 避免阻塞数据接收

3. **增量式优化**
   - 仅优化窗口内节点
   - 避免全局重新优化

## 6. 关键算法总结

| 模块 | 算法 | 作用 | 参数 |
|------|------|------|------|
| LIO前端 | ESKF + IVox3D | 位姿估计 | `max_iteration`, `ivox_grid_resolution` |
| 加速 | Anderson Acceleration | 快速收敛 | `use_aa` |
| 回环检测 | NDT配准 | 闭环检测 | `ndt_score_th`, `max_range` |
| 后端优化 | Pose Graph Optimization | 全局一致性 | 噪声参数 |
| 2D地图 | G2P5投影 | 3D转2D | `grid_map_resolution` |
| 定位 | NDT/ICP匹配 | 地图定位 | `lidar_loc_skip_num` |
| 平滑输出 | IMU外推+平滑 | 高频位姿 | `smooth_factor` |
| 地图管理 | Tiled Loading | 分块管理 | `load_map_size` |
