# Lightning-LM 类与功能实现文档

## 1. 系统架构概览

Lightning-LM采用分层模块化设计，主要分为以下几层：

```
应用层 (app/)
  └─ run_slam_online/offline
  └─ run_loc_online/offline
  
系统层 (core/system/)
  ├─ SlamSystem - SLAM系统接口
  └─ LocSystem - 定位系统接口
  
核心功能层 (core/)
  ├─ lio/ - LiDAR惯性里程计
  ├─ loop_closing/ - 回环检测
  ├─ localization/ - 定位模块
  ├─ maps/ - 地图管理
  ├─ g2p5/ - 2D地图转换
  └─ miao/ - 优化库
  
工具层
  ├─ io/ - 文件I/O
  ├─ utils/ - 工具函数
  ├─ ui/ - 可视化UI
  └─ wrapper/ - ROS2封装
```

**核心算法**:
1. **点云预处理**:
   - 根据LiDAR类型解析点云
   - 提取时间戳
   - 降采样

2. **IMU预积分**:
   - 使用ESKF进行状态预测
   - 计算IMU预积分量

3. **点到面ICP**:
   - 在IVox地图中查找最近邻
   - 构建点到面约束
   - 迭代优化位姿

4. **去畸变**:
   - 根据优化后的位姿
   - 对点云进行运动补偿

5. **关键帧判定**:
   - 检查位移和旋转阈值
   - 生成新关键帧

**关键算法 - ESKF (误差状态卡尔曼滤波)**:

**状态向量**:
```
x = [p, v, R, ba, bg]^T
p: 位置 (3维)
v: 速度 (3维)
R: 旋转 (SO3)
ba: 加速度偏置 (3维)
bg: 陀螺仪偏置 (3维)
```

**预测步**:
```cpp
// 使用IMU测量值进行状态预测
p = p + v*dt + 0.5*R*(a_m - ba)*dt^2
v = v + R*(a_m - ba)*dt
R = R * Exp((w_m - bg)*dt)
ba = ba  // 假设偏置缓慢变化
bg = bg
```

**更新步**:
```cpp
// 使用点到面距离进行观测更新
残差 r = point_to_plane_distance
H = 观测雅可比矩阵
K = P*H^T*(H*P*H^T + R)^-1  // 卡尔曼增益
x = x + K*r
P = (I - K*H)*P
```

### 2.3 回环检测模块

#### 2.3.1 LoopClosing 类

**文件位置**: `src/core/loop_closing/loop_closing.h` / `loop_closing.cc`

**功能**: 基于NDT的回环检测与位姿图优化。

**主要成员**:
```cpp
class LoopClosing {
public:
    struct Options {
        bool verbose_;            // 输出调试信息
        bool online_mode_;        // 在线/离线模式
        
        int loop_kf_gap_;         // 每隔N个关键帧检测一次
        int min_id_interval_;     // 被检查关键帧的ID间隔
        int closest_id_th_;       // 历史帧与当前帧的ID间隔
        double max_range_;        // 候选帧的最大距离
        double ndt_score_th_;     // NDT匹配阈值
        
        // 图优化权重
        double motion_trans_noise_;
        double motion_rot_noise_;
        double loop_trans_noise_;
        double loop_rot_noise_;
    };

private:
    std::vector<Keyframe::Ptr> all_keyframes_;     // 所有关键帧
    std::vector<LoopCandidate> candidates_;        // 回环候选
    std::shared_ptr<miao::Optimizer> optimizer_;   // 位姿图优化器
    AsyncMessageProcess<Keyframe::Ptr> kf_thread_; // 异步处理线程
};
```

**主要方法**:
- `Init(yaml_path)` - 初始化
- `AddKF(kf)` - 添加关键帧
- `DetectLoopCandidates()` - 检测回环候选
- `ComputeLoopCandidates()` - 计算回环位姿
- `PoseOptimization()` - 位姿图优化
- `SetLoopClosedCB(callback)` - 设置回环成功回调

**回环检测流程**:

1. **候选检测**:
```cpp
For each 新关键帧 kf_new:
    if (kf_new.id % loop_kf_gap == 0):  // 每N帧检测一次
        For each 历史关键帧 kf_old:
            if (kf_new.id - kf_old.id > closest_id_th):
                if (distance(kf_new, kf_old) < max_range):
                    添加到候选列表
```

2. **NDT配准**:
```cpp
For each 候选 candidate:
    // 构建NDT网格
    ndt.setInputTarget(kf_old.cloud)
    ndt.setInputSource(kf_new.cloud)
    
    // 配准
    ndt.align(output, initial_guess)
    
    // 评估
    score = ndt.getFitnessScore()
    if (score < ndt_score_th):
        确认为有效回环
```

3. **位姿图优化**:
```cpp
图结构:
  节点: 所有关键帧位姿 {T_w_i}
  边:
    - 里程计边: T_i,i+1 (相邻关键帧)
    - 回环边: T_i,j (回环关键帧)

优化目标:
  minimize Σ ||log(T_i,i+1^-1 * T_i^-1 * T_i+1)||² / σ_odom² +
           Σ ||log(T_loop^-1 * T_i^-1 * T_j)||² / σ_loop²
```

**优化库 - miao**:
- 轻量级图优化库
- 支持增量式优化
- 无需重建优化模型
- 比g2o更快更轻

#### 2.4.4 PoseExtrapolator 类

**文件位置**: `src/core/localization/pose_graph/pose_extrapolator.h` / `pose_extrapolator.cc`

**功能**: 使用IMU进行位姿外推。

**主要方法**:
```cpp
class PoseExtrapolator {
public:
    // 添加位姿观测
    void AddPose(double time, const SE3& pose);
    
    // 添加IMU测量
    void AddImu(double time, const Vec3d& accel, const Vec3d& gyro);
    
    // 外推到指定时刻
    SE3 ExtrapolatePose(double time);
    
    // 获取速度估计
    Vec3d GetVelocity();
};
```

**外推原理**:
```
已知: t0时刻的位姿 T0, 速度 v0
     t0到t之间的IMU数据

IMU积分:
  v(t) = v0 + ∫[t0,t] (R*a - g) dt
  p(t) = p0 + ∫[t0,t] v dt
  R(t) = R0 * Exp(∫[t0,t] ω dt)

输出: T(t) = [R(t) | p(t)]
```

```cpp
// 计算点所在chunk
Vec2i GetChunkId(const Vec3d& pos) {
    return Vec2i(
        floor(pos.x() / chunk_size_),
        floor(pos.y() / chunk_size_)
    );
}

// 加载策略
void UpdateMap(const SE3& pose) {
    Vec2i current = GetChunkId(pose.translation());
    
    // 加载周围chunk
    for (int dx = -load_map_size_; dx <= load_map_size_; ++dx) {
        for (int dy = -load_map_size_; dy <= load_map_size_; ++dy) {
            Vec2i chunk_id = current + Vec2i(dx, dy);
            if (!IsLoaded(chunk_id)) {
                LoadChunk(chunk_id);
            }
        }
    }
    
    // 卸载远处chunk
    for (auto& [id, chunk] : loaded_chunks_) {
        if ((id - current).norm() > unload_map_size_) {
            UnloadChunk(id);
        }
    }
}
```

**动态层管理**:
```cpp
// 添加动态点
void AddDynamicPoint(const PointType& pt, double timestamp) {
    Vec2i chunk_id = GetChunkId(pt);
    auto& chunk = dynamic_chunks_[chunk_id];
    
    // 添加点并记录时间戳
    chunk->AddPoint(pt, timestamp);
    
    // 检查点数限制
    if (chunk->Size() > max_pts_in_dyn_chunk_) {
        chunk->Downsample();
    }
}

// 清理过期动态点
void CleanupDynamicPoints(double current_time) {
    for (auto& [id, chunk] : dynamic_chunks_) {
        if (policy_ == SHORT) {
            chunk->RemovePointsOlderThan(current_time - 10.0);
        } else if (policy_ == LONG) {
            chunk->RemovePointsOlderThan(current_time - 60.0);
        }
        // PERSISTENT: 不清理
    }
}
```

**2D转换算法**:

**1. 地面估计** (如果启用):
```cpp
// RANSAC拟合地面平面
std::vector<PointType> floor_points;
for (auto& pt : cloud) {
    if (pt.z < lidar_height_ - 0.5) {
        floor_points.push_back(pt);
    }
}

// 拟合平面 ax + by + cz + d = 0
Plane floor_plane = RANSAC_FitPlane(floor_points);

// 更新地面高度
floor_height_ = -floor_plane.d / floor_plane.c;
```

**2. 高度过滤**:
```cpp
CloudPtr filtered_cloud;
for (auto& pt : cloud) {
    double height = pt.z - floor_height_;
    if (height > min_th_floor_ && height < max_th_floor_) {
        filtered_cloud->push_back(pt);
    }
}
```

**3. 射线追踪与栅格更新**:
```cpp
Vec2d lidar_pos_2d = lidar_pose.translation().head<2>();

for (auto& pt : filtered_cloud) {
    Vec2d pt_pos_2d = Vec2d(pt.x, pt.y);
    
    // 射线方向
    Vec2d ray_dir = (pt_pos_2d - lidar_pos_2d).normalized();
    double ray_length = (pt_pos_2d - lidar_pos_2d).norm();
    
    // 沿射线更新栅格
    for (double l = 0; l < ray_length; l += grid_map_resolution_) {
        Vec2d pos = lidar_pos_2d + ray_dir * l;
        Vec2i grid_id = PosToGrid(pos);
        
        // 更新为空闲（白色）
        UpdateGrid(grid_id, FREE);
    }
    
    // 终点标记为占据（黑色）
    Vec2i end_grid = PosToGrid(pt_pos_2d);
    UpdateGrid(end_grid, OCCUPIED);
}
```

**4. 占据概率更新** (对数几率法):
```cpp
// 初始化
log_odds[x][y] = 0;

// 观测为占据
log_odds[x][y] += log(p_occupied / (1 - p_occupied));

// 观测为空闲
log_odds[x][y] += log(p_free / (1 - p_free));

// 转换为概率
prob[x][y] = 1 - 1 / (1 + exp(log_odds[x][y]));

// 转换为灰度值
gray[x][y] = (1 - prob[x][y]) * 255;  // 0=黑色(占据), 255=白色(空闲)
```

## 6. 关键算法总结

| 算法/模块 | 实现类 | 核心功能 | 复杂度 |
|----------|--------|---------|--------|
| ESKF | `ESKF` | 误差状态卡尔曼滤波 | O(n³) |
| IVox3D | `IVox` | 增量式体素地图 | O(1)插入, O(log n)查询 |
| Anderson加速 | `AndersonAcceleration` | 加速迭代收敛 | O(m²) |
| NDT | `pclomp::NDT` | 点云配准 | O(n) |
| 位姿图优化 | `miao::Optimizer` | 非线性最小二乘 | O(n³) |
| G2P5 | `G2P5` | 3D转2D投影 | O(n) |
| 分块地图 | `TiledMap` | 空间分块管理 | O(1)访问 |
