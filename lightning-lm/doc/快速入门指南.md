# Lightning-LM 快速入门指南

## 1. 系统简介

Lightning-LM 是一个完整的激光SLAM建图与定位系统，特点包括：
- 快速的3D LiDAR SLAM（基于AA-FasterLIO前端）
- 实时回环检测与闭环优化
- 高精度3D激光定位
- 2D栅格地图生成
- 动静态图层分离定位
- 高频IMU平滑输出（100Hz）
- 低资源占用（纯CPU端不到1核心）

## 2. 环境要求

### 2.1 操作系统
- Ubuntu 22.04（推荐）
- Ubuntu 20.04（未测试但应该可用）

### 2.2 依赖项
- ROS2 Humble 或更高版本
- Pangolin（可视化）
- OpenCV
- PCL 1.15.0+
- yaml-cpp
- glog / gflags
- pcl_conversions

## 3. 安装与编译

### 3.1 安装依赖
在Ubuntu 22.04上一键安装所有依赖：
```bash
cd /path/to/lightning_lm_ws/src/lightning-lm
./scripts/install_dep.sh
```

### 3.2 编译项目
```bash
cd /path/to/lightning_lm_ws
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

### 3.3 编译后的可执行程序
编译完成后会生成以下程序：
- `run_slam_online` - 在线建图（实时传感器数据）
- `run_slam_offline` - 离线建图（数据包回放）
- `run_loc_online` - 在线定位
- `run_loc_offline` - 离线定位
- `run_frontend_offline` - 前端测试
- `run_loop_offline` - 回环检测测试

## 5. 建图操作

### 5.1 离线建图（推荐用于测试）
```bash
# 使用NCLT数据集建图
ros2 run lightning run_slam_offline \
  --config ./config/default_nclt.yaml \
  --input_bag ~/data/NCLT/20130110/20130110.db3
```
- 建图完成后自动保存到 `./data/new_map/` 目录
- 生成文件包括：点云分块文件、`global.pcd`（完整地图）、`map.pgm`（2D栅格地图）

### 5.2 在线建图（实时传感器）
```bash
# 启动建图程序
ros2 run lightning run_slam_online --config ./config/default_nclt.yaml

# 在另一个终端播放数据包
ros2 bag play ~/data/NCLT/20130110/20130110.db3

# 保存地图（可选）
ros2 service call /lightning/save_map lightning/srv/SaveMap "{map_id: new_map}"
```

### 5.3 查看地图
```bash
# 查看完整3D点云地图
pcl_viewer ./data/new_map/global.pcd

# 2D栅格地图保存在
# ./data/new_map/map.pgm（可用图像查看器打开）
```

## 6. 定位操作

### 6.1 准备工作
1. 确保已经完成建图，地图保存在 `./data/new_map/` 目录
2. 在配置文件中设置地图路径：
   ```yaml
   system:
     map_path: ./data/new_map/
   ```
3. 将车辆/传感器放置在建图起点处

### 6.2 离线定位
```bash
ros2 run lightning run_loc_offline \
  --config ./config/default_nclt.yaml \
  --input_bag ~/data/NCLT/20130110/20130110.db3
```

### 6.3 在线定位
```bash
# 启动定位程序
ros2 run lightning run_loc_online --config ./config/default_nclt.yaml

# 在另一个终端播放数据包或启动传感器
ros2 bag play ~/data/NCLT/20130110/20130110.db3
```

### 6.4 接收定位结果
定位程序输出：
- **TF话题**: 与IMU同频（50-100Hz）的位姿信息
- **话题名称**: `/tf` 和 `/tf_static`
- 可以在RViz2中订阅TF查看定位效果

## 7. 在自己设备上调试

### 7.1 配置LiDAR类型
在配置文件中设置 `fasterlio.lidar_type`：
- `1` - Livox系列
- `2` - Velodyne系列
- `3` - Ouster系列
- 其他类型可参考Velodyne设置方式

### 7.2 修改话题名称
```yaml
common:
  lidar_topic: "your_lidar_topic"  # 你的激光话题
  imu_topic: "your_imu_topic"      # 你的IMU话题
```

### 7.3 调试流程建议
1. **先录制数据包**
   ```bash
   ros2 bag record /your_lidar_topic /your_imu_topic -o test_bag
   ```
2. **离线调试建图**
   - 修改配置文件
   - 运行离线建图程序
   - 检查建图效果
3. **离线调试定位**
   - 使用建好的地图
   - 运行离线定位程序
   - 验证定位精度
4. **在线调试**
   - 离线功能正常后再进行在线调试

### 7.4 重要参数说明
```yaml
fasterlio:
  lidar_type: 2              # LiDAR类型
  scan_line: 32              # 扫描线数
  time_scale: 1e-3           # 时间戳缩放（敏感参数）
  point_filter_num: 10       # 点云采样数（越大点越少，速度越快）
  
g2p5:
  esti_floor: false          # 是否动态估计地面（水平雷达可关闭）
  grid_map_resolution: 0.2   # 栅格地图分辨率

system:
  with_loop_closing: true    # 是否启用回环检测
  with_ui: true              # 是否启用3D UI
  with_g2p5: true            # 是否生成栅格地图
```

### 7.5 时间戳注意事项
- 检查点云是否包含每个点的时间戳
- 验证时间戳计算是否正确
- 相关代码位于: `src/core/lio/pointcloud_preprocess.h`
- `fasterlio.time_scale` 参数敏感，需根据实际情况调整

## 8. 常见配置调整

### 8.1 性能优化
```yaml
fasterlio:
  point_filter_num: 10      # 增大可减少点数，提高速度（不建议>10）
  skip_lidar_num: 0         # 跳帧数（增大可提高速度但降低精度）

system:
  with_ui: false            # 关闭UI可节省资源
  enable_lidar_loc_skip: true
  lidar_loc_skip_num: 4     # 定位跳帧数
```

### 8.2 精度优化
```yaml
fasterlio:
  max_iteration: 6          # ICP最大迭代次数
  filter_size_scan: 0.5     # 扫描降采样分辨率
  ivox_grid_resolution: 0.5 # IVox网格分辨率

loop_closing:
  ndt_score_th: 1.0         # NDT匹配阈值（越小要求越严格）
```

### 8.3 大场景配置
```yaml
maps:
  load_map_size: 2          # 加载地图的范围
  unload_map_size: 4        # 卸载地图的范围
  dyn_cloud_policy: persistent  # 动态点云策略（短期/中期/永久）
```

## 10. 故障排查

### 10.1 编译错误
- **PCL相关错误**: 确认PCL版本 >= 1.15.0
- **找不到头文件**: 运行 `./scripts/install_dep.sh`
- **ROS2相关错误**: 确认已source ROS2环境

### 10.2 运行时问题
- **点云未对齐**: 检查时间戳、IMU外参
- **定位漂移**: 调整 `lidar_loc` 相关参数
- **建图不平滑**: 增加 `max_iteration`，调整采样参数
- **程序崩溃**: 检查话题名称、数据格式是否正确

### 10.3 性能问题
- **CPU占用过高**: 减少点云数量、启用跳帧、关闭UI
- **内存占用大**: 减小地图加载范围、降低分辨率
- **延迟较大**: 启用跳帧、减少迭代次数

## 11. 进阶功能

### 11.1 动静态分离定位

lidar_loc:
  update_dynamic_cloud: true      # 启用动态点云更新

pgo:

  force_2d: true         # 强制输出2D位姿
